<title>Schema & In-Memory Platform Configuration Store</title>
<instruction>
Build the runtime data schemas and in-memory platform configuration store:

1. Create `app/schemas/platformConfig.ts`:
   - Define and export Zod schemas and TypeScript types:
     - `workshopModeSchema`: `z.enum(['pretraining', 'live-class'])`.
     - `WorkshopMode`: `z.infer<typeof workshopModeSchema>`.
     - `announcementBannerTypeSchema`: `z.enum(['info', 'warning', 'alert'])`.
     - `AnnouncementBannerType`: `z.infer<typeof announcementBannerTypeSchema>`.
     - `announcementBannerSchema`:
       - `id`: `z.string().min(1)`.
       - `enabled`: `z.boolean()`.
       - `message`: `z.string().max(280)`.
       - `type`: `announcementBannerTypeSchema`.
       - `linkText`: `z.string().max(40).optional()`.
       - `linkUrl`: `z.string().url('URL tidak valid').or(z.string().regex(/^\/[a-zA-Z0-9/_#-]*$/, 'Path relatif tidak valid')).optional().or(z.literal(''))`.
       - `createdAt`: `z.number()`.
       - `updatedAt`: `z.number()`.
       - `updatedBy`: `z.string()`.
     - `AnnouncementBanner`: `z.infer<typeof announcementBannerSchema>`.
     - `publicPlatformConfigSchema`:
       - `workshopMode`: `workshopModeSchema`.
       - `banner`: `announcementBannerSchema.pick({ id: true, enabled: true, message: true, type: true, linkText: true, linkUrl: true })`.
       - `serverTimestamp`: `z.number()`.
     - `PublicPlatformConfig`: `z.infer<typeof publicPlatformConfigSchema>`.
     - `adminPlatformConfigSchema`:
       - `workshopMode`: `workshopModeSchema`.
       - `banner`: `announcementBannerSchema`.
       - `authReadiness`: `z.object({ googleOAuthReady: z.boolean(), adminPasskeyConfigured: z.boolean(), sessionTtlHours: z.number() })`.
       - `environment`: `z.string()`.
       - `serverTimestamp`: `z.number()`.
       - `version`: `z.number()`.
       - `lastModeChange`: `z.object({ mode: workshopModeSchema, changedAt: z.number(), changedBy: z.string(), reason: z.string().optional() }).optional()`.
     - `AdminPlatformConfig`: `z.infer<typeof adminPlatformConfigSchema>`.
     - `updateWorkshopModeInputSchema`:
       - `mode`: `workshopModeSchema`.
       - `reason`: `z.string().max(200).optional()`.
       - `sessionToken`: `z.string().optional()`.
     - `UpdateWorkshopModeInput`: `z.infer<typeof updateWorkshopModeInputSchema>`.
     - `updateAnnouncementBannerInputSchema`:
       - `enabled`: `z.boolean()`.
       - `message`: `z.string().min(1, 'Pesan pengumuman tidak boleh kosong').max(280)`.
       - `type`: `announcementBannerTypeSchema`.
       - `linkText`: `z.string().max(40).optional()`.
       - `linkUrl`: `z.string().url('URL tidak valid').or(z.string().regex(/^\/[a-zA-Z0-9/_#-]*$/, 'Path relatif tidak valid')).optional().or(z.literal(''))`.
       - `sessionToken`: `z.string().optional()`.
     - `UpdateAnnouncementBannerInput`: `z.infer<typeof updateAnnouncementBannerInputSchema>`.

2. Create `app/server/platformStore.ts`:
   - Initialize deterministic in-memory default state:
     - `currentWorkshopMode`: `'pretraining'`.
     - `currentBanner`:
       - `id`: `'banner_init_v1'`.
       - `enabled`: `false`.
       - `message`: `''`.
       - `type`: `'info'`.
       - `linkText`: `''`.
       - `linkUrl`: `''`.
       - `createdAt`: `Date.now()`.
       - `updatedAt`: `Date.now()`.
       - `updatedBy`: `'system'`.
     - `storeVersion`: `1`.
     - `lastModeChange`: `{ mode: 'pretraining', changedAt: Date.now(), changedBy: 'system', reason: 'Initial system default' }`.
   - Implement storage methods:
     - `getPublicPlatformConfig(): PublicPlatformConfig`:
       - Returns `{ workshopMode, banner: { id, enabled, message, type, linkText, linkUrl }, serverTimestamp: Date.now() }`.
       - **Strict Quarantine Rule (T-33-02, T-33-05)**: Strictly omit any secret credentials, internal hashes, tokens, or audit metadata.
     - `getAdminPlatformConfig(): AdminPlatformConfig`:
       - Inspects `getServerConfig()` from `app/server/config.ts`.
       - Computes `authReadiness`:
         - `googleOAuthReady`: `Boolean(config.googleClientId)`.
         - `adminPasskeyConfigured`: `Boolean(config.adminPasskeyHash)`.
         - `sessionTtlHours`: `24`.
       - Returns full administrative view including `workshopMode`, `banner`, `authReadiness`, `environment: config.nodeEnv`, `serverTimestamp: Date.now()`, `version: storeVersion`, `lastModeChange`.
     - `updateWorkshopMode(mode: WorkshopMode, updatedBy = 'master-admin', reason?: string): { success: boolean; mode: WorkshopMode; version: number }`:
       - Updates `currentWorkshopMode`.
       - Increments `storeVersion`.
       - Records `lastModeChange = { mode, changedAt: Date.now(), changedBy, reason }`.
       - Returns `{ success: true, mode, version: storeVersion }`.
     - `updateAnnouncementBanner(input: Omit<UpdateAnnouncementBannerInput, 'sessionToken'>, updatedBy = 'master-admin'): { success: boolean; banner: AnnouncementBanner; version: number }`:
       - Generates new unique ID: `banner_${Date.now()}` whenever banner is modified/broadcast (ensuring all client dismissals are reset for new content).
       - Updates `currentBanner = { id: newId, enabled: input.enabled, message: input.message.trim(), type: input.type, linkText: input.linkText?.trim() || '', linkUrl: input.linkUrl?.trim() || '', createdAt: currentBanner.createdAt, updatedAt: Date.now(), updatedBy }`.
       - Increments `storeVersion`.
       - Returns `{ success: true, banner: currentBanner, version: storeVersion }`.
     - `clearPlatformStoreForTesting()`:
       - Resets state back to deterministic defaults (`mode: 'pretraining'`, `enabled: false`, `version: 1`).
</instruction>

<title>Platform Server RPC Functions & Session Security Isolation</title>
<instruction>
Create the server functions powering public configuration queries and authenticated admin mutations:

1. Update `app/server/session.ts` (if needed):
   - Ensure `assertAdminAuthorized(explicitToken?: string | null)` is exported or available as a centralized authorization utility that validates the session token and throws `UNAUTHORIZED: Sesi Master Admin diperlukan...` on failure.

2. Create `app/server/platform.ts`:
   - Import `createServerFn` from `@tanstack/react-start`.
   - Import schemas from `../schemas/platformConfig.ts`.
   - Import store methods from `./platformStore.ts`.
   - Import `readSessionToken` and `validateAdminSession` from `./session.ts`.
   - Implement `assertAdminAuthorized(explicitToken?: string | null)`:
     - Extracts token from `explicitToken || readSessionToken()`.
     - Validates with `validateAdminSession(token)`.
     - Throws `new Error('UNAUTHORIZED: Sesi Master Admin diperlukan untuk mengakses konfigurasi platform.')` if invalid.
   - Implement `getPublicPlatformConfigFn = createServerFn({ method: 'GET' })`:
     - Public access (no token check).
     - Calls and returns `getPublicPlatformConfig()`.
   - Implement `adminGetPlatformConfigFn = createServerFn({ method: 'GET' })`:
     - Method: `GET`.
     - Validator: accepts optional `{ sessionToken?: string }`.
     - Handler: calls `assertAdminAuthorized(data?.sessionToken)`, then returns `getAdminPlatformConfig()`.
   - Implement `adminUpdateWorkshopModeFn = createServerFn({ method: 'POST' })`:
     - Method: `POST`.
     - Validator: parses `updateWorkshopModeInputSchema`.
     - Handler:
       - Calls `const user = assertAdminAuthorized(data.sessionToken)`.
       - Calls `updateWorkshopMode(data.mode, user.role || 'master-admin', data.reason)`.
       - Returns `{ success: true, mode: data.mode, message: `Mode workshop berhasil diubah menjadi ${data.mode === 'live-class' ? 'Sesi Tatap Muka (Live Class)' : 'Pra-Pelatihan Mandiri (Pre-Training)'}.` }`.
   - Implement `adminUpdateAnnouncementBannerFn = createServerFn({ method: 'POST' })`:
     - Method: `POST`.
     - Validator: parses `updateAnnouncementBannerInputSchema`.
     - Handler:
       - Calls `const user = assertAdminAuthorized(data.sessionToken)`.
       - Calls `updateAnnouncementBanner(data, user.role || 'master-admin')`.
       - Returns `{ success: true, banner: result.banner, message: data.enabled ? 'Pengumuman berhasil disiarkan ke seluruh peserta.' : 'Pengumuman dinonaktifkan.' }`.
</instruction>
