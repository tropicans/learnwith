<task type="auto" id="33-02-01">
<title>Global Announcement Banner Component & Client Layout Mounting</title>
<instruction>
Build the learner-facing Global Announcement Banner component, mount it in the root route layout, and configure styles:

1. Create `app/components/layout/GlobalAnnouncementBanner.tsx`:
   - Component state:
     - `config`: `PublicPlatformConfig | null` (initialized to `null`).
     - `isDismissed`: `boolean` (initialized to `false`).
     - `isLoading`: `boolean` (initialized to `true`).
   - Query on mount:
     - Calls `getPublicPlatformConfigFn()`.
     - In `useEffect`, checks `localStorage.getItem('learnwith_dismissed_banner_id')`.
     - Compares stored dismissed ID against `data.banner.id`.
     - Sets `isDismissed = (storedId === data.banner.id)`.
     - Gracefully handles offline or network errors (catches error and sets `isLoading = false` without throwing or breaking page render).
   - Dismiss handler `handleDismiss()`:
     - Sets `isDismissed = true`.
     - Writes `localStorage.setItem('learnwith_dismissed_banner_id', config.banner.id)`.
   - Rendering logic:
     - Returns `null` if:
       - Still loading without cached data.
       - `config?.banner?.enabled === false`.
       - `!config?.banner?.message || config.banner.message.trim() === ''`.
       - `isDismissed === true`.
     - Otherwise renders:
       `<aside className={`global-announcement-banner banner-type-${config.banner.type}`} role="alert" aria-live="polite">`
       - Inner container `.banner-inner`:
         - Icon badge based on type:
           - `'info'`: `ℹ️`
           - `'warning'`: `⚠️`
           - `'alert'`: `🚨`
         - Text paragraph `.banner-message`: displays `config.banner.message`.
         - Optional action button/link (if `config.banner.linkUrl` and `config.banner.linkText` exist):
           - If `linkUrl` starts with `http://` or `https://`:
             `<a href={linkUrl} target="_blank" rel="noopener noreferrer" className="banner-link-btn">` with text and external link icon `↗`.
           - If `linkUrl` is a relative path (e.g. `/course/ai`):
             `<Link to={linkUrl} className="banner-link-btn">` with text.
         - Dismiss button:
           `<button type="button" onClick={handleDismiss} className="banner-close-btn" aria-label="Tutup pengumuman">✕</button>`.

2. Update `app/routes/__root.tsx`:
   - Import `GlobalAnnouncementBanner` from `@/components/layout/GlobalAnnouncementBanner`.
   - Mount `<GlobalAnnouncementBanner />` inside `RootComponent()` directly inside `<RootDocument>` before `<div className="app-container">`:
     ```tsx
     <RootDocument>
       <GlobalAnnouncementBanner />
       <div className={`app-container ${isHome ? 'view-home' : ''} ${isAdmin ? 'view-admin' : ''}`}>
         <Header />
         <Outlet />
       </div>
     </RootDocument>
     ```
   - **Crucial Layout Invariant**: Mounting above `.app-container` completely avoids disturbing the 2-row CSS grid (`--header-height 1fr`) and prevents sidebar displacement across `/`, `/course/ai`, `/course/word`, and `/admin`.

3. Update `app/components/layout/Header.tsx` (optional operational indicator):
   - Ensure header brand and search elements retain clean z-index hierarchy and responsive behavior when banner is visible above it.

4. Update `assets/css/components.css` and mirror to `public/assets/css/components.css`:
   - Add styles for `.global-announcement-banner`:
     - Width 100%, relative or sticky top, z-index 9999.
     - Type color schemes:
       - `.banner-type-info`: Soft blue theme (`background: #eff6ff; color: #1e40af; border-bottom: 1px solid #bfdbfe;`).
       - `.banner-type-warning`: Warm amber theme (`background: #fffbeb; color: #92400e; border-bottom: 1px solid #fde68a;`).
       - `.banner-type-alert`: High-visibility red theme (`background: #fef2f2; color: #991b1b; border-bottom: 1px solid #fecaca; font-weight: 500;`).
     - Inner flex container `.banner-inner`: max-width 1440px, auto-margins, flex alignment, gap 0.75rem, padding 0.5rem 1rem.
     - `.banner-message`: text sizing 0.875rem, flex 1, line-height 1.4.
     - `.banner-link-btn`: pill button with subtle background/hover effect matching theme, font-weight 600, text-decoration none, white-space nowrap.
     - `.banner-close-btn`: subtle transparent button with hover opacity, min 32x32px hit area for accessibility.
     - Responsive breakpoint (`@media (max-width: 640px)`): wraps message and action link neatly.
   - Synchronize identical rules between `assets/css/components.css` and `public/assets/css/components.css`.
</instruction>
