<task type="auto" id="31-01-02">
<title>Dashboard KPI Cards & Filter Toolbar Components</title>
<instruction>
Build the aggregate KPI metric summary cards and interactive filter toolbar:
1. Create `app/components/admin/DashboardKPIs.tsx`:
   - Accept props: `stats: TelemetryDashboardStats`, `isLoading?: boolean`.
   - Render 4 responsive KPI cards matching the LearnWith design system (`ADMIN-DASH-01`):
     a. **Total Peserta Terdaftar**: Displays `stats.totalParticipants`, a live pulsing green dot, and subtitle showing `${stats.activeParticipants} aktif dalam 15 menit terakhir`.
     b. **Kelulusan Checkpoint**: Displays `${stats.checkpointCompletionRate}%`, a visual progress fill bar, and subtitle showing `Akumulasi Checkpoint 1–3 seluruh modul`.
     c. **Rata-rata Evaluasi Kuis**: Displays `${stats.averageQuizScore} / 100` with a color-coded status badge (>=70 green, <70 amber, or 'Belum ada data' if 0 quiz takers), and subtitle `Evaluasi pemahaman ASN (Modul Word)`.
     d. **Kesiapan Workshop**: Displays `${stats.readyRatio}% Siap`, a comparative split bar showing ready vs clinic ratios, and subtitle `${stats.clinicRatio}% Perlu Pendampingan Klinik`.
   - Implement pure CSS / SVG indicators with zero external charting library dependencies.
   - Include skeleton loading placeholders when `isLoading` is true.
2. Create `app/components/admin/ParticipantFilterToolbar.tsx`:
   - Accept props: `courseFilter: 'all' | 'ai' | 'word'`, `readinessFilter: 'all' | 'ready' | 'clinic' | 'pending'`, `searchQuery: string`, `totalCount: number`, `filteredCount: number`, `autoRefresh: boolean`, `isRefreshing: boolean`, `onCourseChange: (val) => void`, `onReadinessChange: (val) => void`, `onSearchChange: (val) => void`, `onToggleAutoRefresh: () => void`, `onManualRefresh: () => void`.
   - Implement controls matching `ADMIN-DASH-02`:
     - Course selector pills / dropdown (`Semua Kursus`, `🤖 AI Agent`, `📝 Word ASN`).
     - Readiness status selector pills / dropdown (`Semua Status`, `✅ Siap Workshop`, `🚨 Perlu Klinik`, `⏳ Berprogres`).
     - Search input field with search icon, placeholder `"Cari nama peserta, instansi, atau ID..."`, debounced change handler, and clear button (`✕`).
     - Live count badge: `"Menampilkan ${filteredCount} dari ${totalCount} peserta"`.
     - Auto-refresh toggle button (15 detik) with active pulsing status and manual `"Segarkan"` button with spinning refresh icon during fetch.
</instruction>

<task type="auto" id="31-01-03">
<title>Participant Directory Table & Admin Shell Integration</title>
<instruction>
Build the responsive participant directory table and integrate the dashboard view into `AdminShell`:
1. Create `app/components/admin/ParticipantTable.tsx`:
   - Accept props: `participants: ParticipantRecord[]`, `isLoading?: boolean`, `onInspectParticipant: (participant: ParticipantRecord) => void`, `sortBy: string`, `sortOrder: 'asc' | 'desc'`, `onSort: (column: string) => void`.
   - Render structured table matching `ADMIN-DASH-02`:
     - Column **Peserta**: Participant name (bold), agency/unit kerja (secondary text), and monospace ID badge (`usr-...`).
     - Column **Kursus**: Badge indicating `🤖 AI` or `📝 Word`.
     - Column **Progres**: Percentage bold text, visual progress bar (styled with `var(--accent-primary)`), and task count badge (`${completedTasks}/${totalTasks}`).
     - Column **Checkpoints**: Horizontal container of 3 mini pills (CP1, CP2, CP3) with status colors and icons (`✓` green for passed, `✗` red for failed, `○` amber/muted for pending).
     - Column **Nilai Kuis**: Quiz score pill (e.g. `90/100`) or em-dash (`—`) for courses without quiz submissions.
     - Column **Status Kesiapan**: Badge with icon:
       - `ready`: Green badge `"Siap Workshop"`.
       - `clinic`: Red badge `"Perlu Klinik"`.
       - `pending`: Amber badge `"Berprogres"`.
     - Column **Aktivitas Terakhir**: Relative time (e.g., `"2 mnt lalu"`, `"1 jam lalu"`, `"Hari ini"`) with active indicator dot (green for active within 15 mins, gray for idle) and tooltip with full ISO timestamp.
     - Column **Aksi**: Action button `"Inspeksi"` / eye icon that triggers `onInspectParticipant(participant)`.
   - Support sortable column headers (by name, progress, last active).
   - Render helpful empty state illustration when search/filter returns zero records.
2. Create `app/components/admin/AdminDashboardView.tsx`:
   - State management:
     - `filter`: course (`all` | `ai` | `word`), readiness (`all` | `ready` | `clinic` | `pending`), search string.
     - `participants`: array of `ParticipantRecord`.
     - `stats`: `TelemetryDashboardStats`.
     - `autoRefresh`: boolean (default true).
     - `isRefreshing`: boolean.
     - `selectedParticipant`: `ParticipantRecord | null` (for modal in Plan 31-02).
   - Data loading:
     - Fetches from `getParticipantTelemetryListFn` with current filter parameters.
     - Sets up 15-second polling interval when `autoRefresh` is enabled, pausing when window loses focus or modal is open.
   - Compose layout:
     - Header area with title `"Pusat Kendali Peserta & Pelatihan"`.
     - Render `<DashboardKPIs stats={stats} isLoading={isRefreshing && !participants.length} />`.
     - Render `<ParticipantFilterToolbar ... />`.
     - Render `<ParticipantTable participants={participants} onInspectParticipant={handleInspect} ... />`.
3. Update `app/components/admin/AdminShell.tsx`:
   - When `activeTab === 'dashboard' || activeTab === 'telemetry'`, render `<AdminDashboardView initialTab={activeTab} />` as the primary body view instead of the static placeholder card.
   - Retain placeholder views for uncompleted roadmap tabs (`passkeys`, `troubleshooting`, `settings`).
</instruction>
