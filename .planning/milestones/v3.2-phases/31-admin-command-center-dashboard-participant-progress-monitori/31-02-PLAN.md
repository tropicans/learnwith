<task type="auto" id="31-02-01">
<title>Participant Detail Inspector Modal / Drawer Component</title>
<instruction>
Build the granular participant inspection modal dialog:
1. Create `app/components/admin/ParticipantDetailModal.tsx`:
   - Accept props: `participant: ParticipantRecord | null`, `isOpen: boolean`, `onClose: () => void`.
   - Implement accessibility standards:
     - Backdrop overlay with blur (`background: rgba(0, 0, 0, 0.7); backdrop-filter: blur(4px)`).
     - Container attributes: `role="dialog"`, `aria-modal="true"`, `aria-labelledby="modal-participant-title"`.
     - ESC key listener on window to dismiss modal.
     - Autofocus close button (`✕`) on open and body scroll lock when open.
   - Render structured dossier sections matching `ADMIN-DASH-03`:
     a. **Header**: Participant name, agency / unit kerja, participant ID monospace tag, course badge (`🤖 AI Agentic` vs `📝 Pengolahan Kata ASN`), and prominent close button.
     b. **Readiness Hero Banner**: Prominent banner styled based on `readinessStatus`:
        - `ready`: Green highlight with checkmark, `"Peserta Siap Mengikuti Sesi Workshop Tatap Muka"`.
        - `clinic`: Red alert with warning icon, `"Peserta Memerlukan Pendampingan Khusus di Klinik Teknis"`.
        - `pending`: Amber status with clock icon, `"Peserta Sedang Menyelesaikan Modul Mandiri"`.
     c. **Checkpoints 1–3 History**:
        - CP-1: Verifikasi Lingkungan / Format Dasar (badge `passed`, `failed`, or `pending`).
        - CP-2: Uji Kredensial / Tata Naskah (badge `passed`, `failed`, or `pending`).
        - CP-3: Validasi Integrasi / Finalisasi Dokumen (badge `passed`, `failed`, or `pending`).
     d. **Evaluasi Kuis**:
        - For Word course: display score (`${participant.quizScore} / 100`), passing indicator (passing threshold >= 70), and evaluation remark.
        - For AI course: display note that AI evaluation is validated via live terminal checkpoints CP-1 through CP-3.
     e. **Rincian Checklist Modul**:
        - List modular tasks (e.g. grouped by Module 1-4 for AI or Bab I-V for Word).
        - For each task, show completion icon (`✓ Selesai` in green or `○ Belum` in muted text) based on `participant.taskChecklist`.
     f. **Footer Metadata**: Monospace timestamps for `Waktu Terdaftar (serverReceivedAt)`, `Aktivitas Terakhir (lastActiveAt)`, and `Client ID`.
2. Connect `ParticipantDetailModal` into `AdminDashboardView.tsx`:
   - Bind `selectedParticipant` state to modal `isOpen={Boolean(selectedParticipant)}` and pass `onClose={() => setSelectedParticipant(null)}`.
</instruction>

<task type="auto" id="31-02-02">
<title>1-Click CSV & JSON Export Engine, UI Controls & Admin Styling</title>
<instruction>
Implement browser-side export utilities and interface controls:
1. Create `app/utils/adminExport.ts`:
   - Implement `generateParticipantCsv(participants: ParticipantRecord[]): string` (`ADMIN-DASH-04`):
     - Prepend UTF-8 Byte Order Mark (`\uFEFF`) at index 0 for Excel Windows UTF-8 compatibility.
     - Include standard header line:
       `"ID Peserta","Nama Peserta","Instansi / Unit Kerja","Kategori Kursus","Progres (%)","Tugas Selesai","Total Tugas","Checkpoint 1","Checkpoint 2","Checkpoint 3","Skor Kuis","Status Kesiapan","Waktu Terdaftar","Aktivitas Terakhir"`
     - Format each participant row:
       - Escape commas, double quotes, and line breaks according to RFC 4180 (double internal `"` to `""` and wrap cell in `""`).
       - Sanitize formula injection: if any cell value starts with `=`, `+`, `-`, `@`, `\t`, or `\r`, prepend a single quote `'` before wrapping.
       - Format timestamps as readable local or ISO date strings.
   - Implement `generateParticipantJson(participants: ParticipantRecord[], stats?: TelemetryDashboardStats, filter?: TelemetryQueryFilter): string`:
     - Return formatted JSON string (`JSON.stringify(..., null, 2)`) with top-level structure:
       `{ exportedAt, exportedBy: "Master Admin", version: "1.0", totalRecords, summary, filtersApplied, participants }`.
   - Implement `triggerFileDownload(content: string, filename: string, mimeType: string): void`:
     - Create `Blob`, construct temporary `URL.createObjectURL`, click synthetic anchor, and revoke object URL cleanly.
2. Create `app/components/admin/ExportControls.tsx`:
   - Render two export action buttons:
     - `"📄 Ekspor CSV (Excel)"`
     - `"📦 Ekspor JSON"`
   - On click, generate data from current participants list, trigger download with timestamped filename (`learnwith-peserta-YYYY-MM-DD.csv` / `.json`), and show visual download feedback toast.
   - Place `<ExportControls />` in `AdminDashboardView.tsx` (in toolbar or table action header).
3. Update `assets/css/admin.css` and copy to `public/assets/css/admin.css`:
   - Add styles for KPI cards grid, live indicators, mini progress bars, split ratio bar.
   - Add styles for filter toolbar, search input, status pills, table cells, checkpoint badges.
   - Add styles for detail modal dialog overlay, dossier cards, checklist list, and export buttons.
</instruction>
