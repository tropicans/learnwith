<threat_model>
## Trust Boundaries
- Browser DOM events and user clipboard interaction.
- Print dialog rendering (`window.print()`).
- URL search parameters (`?mode=pretraining` vs `?mode=live-class`).

## Threat Analysis
- **Clipboard API Failure in Insecure Contexts / Iframe**: `navigator.clipboard.writeText` might fail or reject if permissions are restricted.
  - *Mitigation*: Fallback using `document.execCommand('copy')` on a temporary hidden textarea as in prototype `app.js`.
- **CSS Layout Breakage on Mobile / Desktop**: Adding `#app-sidebar` to `course.ai.tsx` might misalign `.app-container` grid.
  - *Mitigation*: Match existing CSS `.app-sidebar { grid-area: sidebar; }` and desktop media query rules in `main.css`.
- **Navigation Anchor Desynchronization**: Hash links (`#sec-target`, `#sec-module-1`, etc.) must match exact section `id`s across the pretraining page.
  - *Mitigation*: Audit all anchor target IDs against components rendered in `course.ai.tsx`.
</threat_model>
