## Overview

Milestone v2.0 transformed the platform from a single-workshop companion into a robust **multi-course training platform**. While keeping the original Course 1 (*Hands-on Agentic AI: Dari Chat ke Kalender*) 100% active, backward-compatible, and isolated, Milestone v2.0 introduced Course 2 (*Pengolahan Kata Tingkat Lanjut: Dari Dokumen Berantakan ke Standar Kedinasan Otomatis*) designed for civil servants (ASN) at BPSDM DKI Jakarta.

The milestone delivered developer gate protection, four comprehensive instructional modules (Bab I–IV), 3 verification checkpoint gates, visual keyboard shortcuts, Pergub DKI No. 14/2020 callout cards, an interactive 20-question knowledge evaluation quiz (Bab V) with instant pedagogical explanations, a self-reflection competency checklist, and a multi-channel graduation report exporter formatted for WhatsApp, Telegram, and print certificates.

## Milestone Summary

**Key Decisions:**
- **Decision**: Multi-Course Namespacing (`learnwith_ai_state_v1` vs `learnwith_word_state_v1`) (Rationale: Complete isolation prevents data collisions and state contamination between different workshop cohorts).
- **Decision**: Soft Gate with Passkey (`buka-kata`) & URL parameter (`?course=word&unlock=dev`) (Rationale: Allows course facilitators to preview and test material without exposing unreleased courses to current AI workshop attendees).
- **Decision**: BPSDM Weighted Grading (70% Portfolio + 30% Quiz) (Rationale: Accurately reflects Indonesian civil service training regulations prioritizing hands-on document production over pure memorization).
- **Decision**: High-Fidelity Official Kop Surat Certificate Slip in DOM (Rationale: Allows immediate physical or PDF printing of completion verification directly from the browser).

**Issues Resolved:**
- Resolved state collision during course switching by resetting scoped DOM components while retaining persistent storage.
- Resolved search indexing isolation so search queries dynamically filter items belonging to the active course view.
- Added regex sanitizers to graduation report exports to ensure clean formatting across messaging platforms.

**Technical Debt Incurred:**
- Non-blocking test runner warning regarding CommonJS require statements when evaluated outside Node.js test harnesses.
- Validation documents `10-VALIDATION.md` and `11-VALIDATION.md` remain marked as draft frontmatter; verified via automated test suites.
