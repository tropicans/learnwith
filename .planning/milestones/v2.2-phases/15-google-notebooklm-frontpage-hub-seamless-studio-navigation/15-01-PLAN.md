# Plan 15-01: Google NotebookLM Frontpage Hub & Seamless Studio Navigation

## Objective
Deliver an authentic Google NotebookLM Frontpage Hub (`#container-home`) displaying platform welcome hero, search/filter helper, and notebook card gallery for Course 1, Course 2, and civil service standards, with seamless two-way studio navigation and complete backward compatibility.

## Requirements
- `HOME-01`: Dedicated NotebookLM Frontpage Hub (`#container-home`) displaying platform welcome hero, search/filter helper, and notebook card gallery for Course 1, Course 2, and BPSDM Civil Service standards.
- `HOME-02`: Clean full-width canvas on home view (`.view-home` on `.app-container` hides `.app-sidebar` and centers `.app-main`).
- `HOME-03`: Header adaptively displays clean brand on Frontpage and breadcrumb pill on Studio Workspace views.
- `HOME-04`: Seamless two-way navigation: clicking notebook cards enters Studio Workspace, clicking `learnwith` brand or `🏠 Beranda Kursus` in dropdown returns to Frontpage.
- `HOME-05`: URL routing supports `?course=ai`, `?course=word`, and default root without parameters rendering the NotebookLM Frontpage with 100% backward test compatibility.

## Tasks
1. **Markup (index.html)**:
   - Add `#container-home` inside `.app-main` with NotebookLM hero banner and notebook card grid.
   - Wrap `header-brand-platform` / `header-brand-icon` with an interactive button `#brand-home-link`.
   - Add `🏠 Beranda Kursus` dropdown item `#item-course-home` in `#course-dropdown-menu`.
2. **Styling (assets/css/main.css & assets/css/components.css)**:
   - Implement `.container-home`, `.home-hero`, `.home-chips`, `.notebook-grid`, and `.notebook-card`.
   - Implement `.view-home` rules hiding sidebar and centering main canvas.
   - Ensure header breadcrumb separator and dropdown are hidden when on home view.
3. **Behavior (assets/js/app.js)**:
   - Implement `switchView(viewMode, courseId, updateUrl)` supporting `'home'` and `'workspace'`.
   - Wire event listeners for notebook cards, brand home button, and dropdown home item.
   - Support URL parameters: `?course=ai`, `?course=word`, and default root to home.
4. **Verification**:
   - Update `scratch/test_integration.py` to assert home view, card clicking, breadcrumb transitions, and 0 console errors.
