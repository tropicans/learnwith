# Plan 14-01: Workspace Studio Navigation, Sidebar De-duplication & Material 3 Polishing

## Objective
Streamline the sidebar workspace navigation by eliminating redundant course/mode switchers on desktop, polish mobile drawer touch-targets, synchronize Course 2 stat cards to real numbers (4 Bab, 3 Checkpoints, 28 Checklist steps), soften the document readiness card into an encouraging Material 3 progress banner, and refine the search bar into a Google-style pill input.

## Requirements
- `WORK-01`: Sidebar on desktop (screens ≥ 1024px) hides redundant duplicate switchers, immediately surfacing module curriculum links without pushing content below the fold.
- `WORK-02`: Course 1 mode switcher (Pra-Training vs Hari-H Kelas) on desktop resides exclusively in the header as a clean, segmented Material 3 pill control.
- `WORK-03`: Mobile header displays compact logo and hamburger menu without text wrapping or multi-line button breaking; mobile sidebar drawer cleanly accommodates touch-friendly course and mode selection (≥ 44px touch targets).
- `POLISH-01`: Course 2 hero stat cards synchronized to real numbers: 4 Bab, 3 Checkpoints, 28 Checklist steps, and dynamic progress counter (`0/28 Langkah Selesai`).
- `POLISH-02`: Document readiness status card redesigned from an alarming orange warning box into an encouraging, calm progress card.
- `POLISH-03`: Search bar styled with Google-style rounded pill container, comfortable padding, and non-overlapping `Ctrl+K` key badge.

## Tasks

### Task 1: Sidebar De-duplication & Responsive Drawer Tuning (WORK-01, WORK-02, WORK-03)
- In `assets/css/main.css`:
  - Add desktop rule (`@media (min-width: 1024px)`) hiding `.sidebar-course-selector-container` and `.sidebar-mode-switcher-container`.
  - Ensure `.sidebar-nav-group` and `.nav-group` start at the very top of the sidebar on desktop.
  - In mobile media queries (`@media (max-width: 1023px)`), ensure `.sidebar-course-selector-container` and `.sidebar-mode-switcher-container` are neatly visible with minimum 44px touch height, clear border separation, and rounded Material 3 cards.

### Task 2: Search Bar Pill Container Refinement (POLISH-03)
- In `assets/css/main.css`:
  - Refine `.header-search-container` and `.header-search-input-wrapper`.
  - Style `.header-search-input` as a full pill (`border-radius: 9999px`) with subtle surface background, crisp hover/focus borders, and comfortable left/right padding.
  - Position `.header-search-kbd` inside the pill without overlapping long text queries.
