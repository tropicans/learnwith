  <action>
    1. In `assets/js/state.js`, add `activeMode: 'pretraining'` to `DEFAULT_STATE`.

    3. Add `getActiveMode()` method returning `this.state.activeMode || 'pretraining'`.

    5. In `resetAll()`, reset `activeMode` back to `'pretraining'`.

       - Toggle sidebar navigation groups:
         - `#nav-group-pretraining`: visible (`display: ''`) when `mode === 'pretraining'`, hidden (`display: 'none'`) otherwise.
         - `#nav-group-liveclass`: visible (`display: ''`) when `mode === 'live-class'`, hidden (`display: 'none'`) otherwise.

         - Pra-Training: "Hermes Agent + 9Router • Pemula"
