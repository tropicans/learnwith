  <files>index.html</files>
  <action>
    In `index.html`, replace the Phase 8 placeholder inside `<section id="sec-live-troubleshooting" class="content-section" data-section="sec-live-troubleshooting">` with:
    1. A section header styled consistently with existing app sections.
    2. A dedicated toolbar (`.troubleshoot-toolbar`):
       - Search wrapper with `#live-troubleshoot-search-input` and placeholder "Cari kendala live (hermes, endpoint, gateway, allowlist, oauth)...".
       - Filter pills container (`#live-troubleshoot-filter-pills`) containing 5 button elements:
         - `data-category="all"`: "Semua Kendala Live (7)" (active by default, aria-pressed="true")
         - `data-category="9router-live"`: "9Router & Endpoint"
         - `data-category="hermes-cli"`: "Hermes CLI"
         - `data-category="telegram-gateway"`: "Telegram Gateway"
         - `data-category="google-oauth"`: "Google OAuth"
    3. Grid container (`#live-troubleshoot-cards-container` with `.troubleshoot-grid`):
       - Card 1 (`data-live-trouble-category="hermes-cli"`): `hermes` tidak dikenali (Penyebab: terminal belum restart setelah installer; Solusi: tutup semua PowerShell, buka ulang, jalankan `hermes doctor`).
       - Card 2 (`data-live-trouble-category="9router-live"`): Hermes tidak menjawab / 9Router connection refused (Penyebab: 9router mati atau endpoint salah; Solusi: buka http://localhost:20128, jalankan `9router`, cek http://localhost:20128/v1).
       - Card 3 (`data-live-trouble-category="9router-live"`): Model gagal dipanggil / API key 9Router invalid (Penyebab: key belum terdaftar di 9Router; Solusi: generate key baru di dashboard 9Router, update konfigurasi lokal tanpa mengirim key ke chat).
       - Card 4 (`data-live-trouble-category="telegram-gateway"`): Bot Telegram tidak merespons (Penyebab: gateway mati atau token salah; Solusi: `hermes gateway status`, periksa token lokal dan log gateway).
       - Card 5 (`data-live-trouble-category="telegram-gateway"`): Bot membalas `unauthorized` (Penyebab: ID telegram tidak ada di TELEGRAM_ALLOWED_USERS; Solusi: ambil User ID dari @userinfobot, perbarui allowlist, jalankan `hermes gateway stop` lalu `hermes gateway start`).
       - Card 6 (`data-live-trouble-category="google-oauth"`): OAuth Google gagal (Penyebab: client OAuth bukan Desktop app atau Test User belum ditambahkan; Solusi: periksa jenis OAuth Client ID di GCP Console, pastikan berjenis Desktop app, tambahkan email latihan ke Test Users di OAuth Consent Screen).
       - Card 7 (`data-live-trouble-category="google-oauth"`): Google Calendar tidak berubah (Penyebab: login ke akun/kalender Google yang berbeda; Solusi: pastikan kalender latihan aktif di browser, kirim prompt baca kalender, lalu ulangi prompt buat agenda dummy).
    Ensure each card has 1-click copy buttons for terminal commands with `.btn-copy` and `data-clipboard-text`.
  </action>
