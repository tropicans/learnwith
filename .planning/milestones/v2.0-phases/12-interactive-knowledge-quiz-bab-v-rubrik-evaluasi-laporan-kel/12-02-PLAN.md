<threat_model>
- **T-12-04 (UI State Desynchronization):** Re-rendering or resetting quiz could cause UI buttons and explanations to remain stuck in previous states. Mitigation: setupWordQuiz() resets all option button classes (.selected, .correct, .incorrect) and hides explanations on reset.
- **T-12-05 (DOM Injection / XSS in Live Report Preview):** Participant input in live preview could execute malicious script if injected via innerHTML. Mitigation: Use textContent / innerText for all live text replacement in #preview-word-report-text and certificate transcript cells.
- **T-12-06 (Clipboard Denial in Unsecured Contexts):** Modern clipboard API may reject in non-HTTPS environments. Mitigation: Graceful fallback using temporary textarea and document.execCommand('copy').
- **T-12-07 (Print Layout Bleed):** Printing while in Course 2 could render long module contents. Mitigation: Strict @media print CSS rules hide all sibling sections and display only the certificate layout.
</threat_model>
