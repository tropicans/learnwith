## Overview

Milestone v1.1 expanded the web application from its v1.0 preparation baseline (`PANDUAN-PRE-TRAINING.md`) into a complete dual-purpose workshop companion accommodating the live in-class session (`PANDUAN-PRAKTIK-KELAS.md`). Across four sequential phases (Phases 5–8), we built a seamless mode switcher, interactive modules for 9Router model alignment and Hermes CLI installation, Telegram gateway wiring with strict allowlists, Google Calendar OAuth integration, an expanded live troubleshooting hub, dynamic in-class completion tracking (Checkpoints 4–9), and a 1-click final report exporter for instructors.

## Milestone Summary

**Key Decisions:**
- Decision: Dual Workshop Mode switcher with persistent scoped views (Rationale: Enables seamless toggling between Pra-Training and Hari-H Praktik Kelas without full-page reloads or state conflicts).
- Decision: Client-side headless test execution with native Microsoft Edge runner (Rationale: Allows automated CI-grade DOM unit testing without npm/node runtime dependency on Windows host).
- Decision: Zero-credential persistence with regex sanitization on all exports (Rationale: Enforces strict data privacy for participant Telegram bot tokens, Google Client secrets, and local paths).
- Decision: Granular Checkpoints 4–9 with three-tier readiness status (`BELUM SIAP`, `DALAM PRAKTIK`, `SELESAI (SUKSES)`) (Rationale: Delivers instant visual feedback and structured reporting for workshop instructors).

**Issues Resolved:**
- Resolved category-specific search and filter isolation between Pra-Training and Live Workshop troubleshooting sections.
- Integrated robust log sanitizer ensuring Telegram Bot Tokens, Bearer tokens, and Windows username file paths are safely redacted before export.

**Issues Deferred:**
- In-browser simulated PowerShell terminal sandbox (deferred to future milestone).
- Live health check ping button to `http://localhost:20128/v1` (deferred to future milestone).

**Technical Debt Incurred:**
- None. All 19 requirements verified with 153 assertions across 6 automated test suites passing with 0 failures.
