<task type="auto" id="34-01-01">
<title>Define Course Lifecycle Zod Schemas and Transition Rules</title>
<instruction>
Create app/schemas/courseLifecycle.ts:
- Define CourseLifecycleStatus schema: z.enum([active, hidden, archived, deleted]).
- Define CourseLifecycleRecord schema: object with id (string), status (CourseLifecycleStatus), title (string), updatedAt (number), updatedBy (string), reason (optional string).
- Define PublicCourseStatusProjection schema: object with id (string), status (CourseLifecycleStatus), isAvailable (boolean), isDiscoverable (boolean).
- Define updateCourseStatusInputSchema: object with courseId (string), targetStatus (CourseLifecycleStatus), sessionToken (optional string), reason (optional string max 200).
- Export ALLOWED_STATUS_TRANSITIONS map defining valid state transitions:
  - active: [hidden, archived, deleted]
  - hidden: [active, archived, deleted]
  - archived: [active, hidden, deleted]
  - deleted: [active] (restore)
- Export helper function isValidStatusTransition(from: CourseLifecycleStatus, to: CourseLifecycleStatus): boolean.
</instruction>

<task type="auto" id="34-01-02">
<title>Implement In-Memory Course Lifecycle Server Store</title>
<instruction>
Create app/server/courseLifecycleStore.ts:
- Maintain an in-memory Map of course lifecycle records, initialized with:
  - ai: { id: ai, status: active, title: Hands-on Agentic AI, updatedAt: Date.now(), updatedBy: system }
  - word: { id: word, status: active, title: Pengolahan Kata Tingkat Lanjut, updatedAt: Date.now(), updatedBy: system }
- Maintain storeVersion counter and auditLog array of change events.
- Implement getCourseLifecycleRecords(): CourseLifecycleRecord[].
- Implement getCourseLifecycleRecord(courseId: string): CourseLifecycleRecord | undefined.
- Implement updateCourseLifecycleStatus(courseId: string, targetStatus: CourseLifecycleStatus, updatedBy?: string, reason?: string): { success: boolean; record: CourseLifecycleRecord; version: number }.
  - Enforce isValidStatusTransition; throw Error if transition is invalid.
  - Increment storeVersion and append entry to auditLog.
- Implement getPublicCourseStatusProjections(): PublicCourseStatusProjection[] where isDiscoverable = (status === active) and isAvailable = (status === active || status === hidden).
- Implement clearCourseLifecycleStoreForTesting(): reset store to default initial state.
</instruction>
