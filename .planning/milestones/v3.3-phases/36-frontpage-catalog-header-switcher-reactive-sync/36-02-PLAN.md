# Phase 36 — Plan 02: Global Header Course Switcher & Root Loader Reactive Sync

## Executive Summary
Synchronize global application navigation with real-time course lifecycle status (`COURSE-SYNC-02`, `COURSE-SYNC-01`). Establish a centralized navigation metadata registry (`COURSE_NAV_REGISTRY`) in `app/data/courses.ts` (per D-06). Enhance the root layout route `app/routes/__root.tsx` with a synchronous SSR loader fetching public course projections (per D-05) and a global `BroadcastChannel` listener triggering `router.invalidate()` across all open tabs upon administrative changes (per D-14). Wire status projections down into `app/components/layout/Header.tsx` and `app/components/layout/CourseSwitcher.tsx` to dynamically display active courses, badge directly accessed unlisted courses (per D-07), and display an informative disabled note when all courses are inactive (per D-08). Wire cache invalidation and broadcast emissions in `AdminCourseManagementView.tsx` (per D-13).

---

<threat_model>
### ASVS Level 1 Threat Modeling

- **Threat Reference:** T-36-02 (Navigation Leakage & Stale Access Desynchronization)
- **Threat Vector:** Stale client navigation menus displaying deactivated or deleted courses, or leaking hidden course titles to participants browsing unrelated public pages.
- **ASVS Control:** ASVS 4.0.3 v5.1.3 (Dynamic access control propagation and least-privilege UI presentation).
- **Mitigation:**
  - `CourseSwitcher` dynamically resolves items strictly against active courses from `courseStatuses` projected by the server.
  - Hidden courses are only displayed in the switcher when the participant is ALREADY directly visiting that specific hidden course URL (per D-07).
  - Cross-tab `BroadcastChannel` messages only contain metadata (`courseId`, `targetStatus`, `timestamp`), and trigger a full authenticated/SSR revalidation via `router.invalidate()` rather than evaluating untrusted client messages directly.
</threat_model>

<must_haves>
### Truths
- `app/routes/__root.tsx` loader must invoke `getPublicCourseStatusesFn()` so header and switcher have synchronous SSR status data without client waterfalls (per D-05).
- `COURSE_NAV_REGISTRY` in `app/data/courses.ts` must centralize navigation metadata (`id`, `title`, `desc`, `icon`, `path`, `searchParams`, `isLocked`) (per D-06).
- If a participant directly accesses a hidden course URL (e.g. `/course/ai`), `CourseSwitcher` must display the current course title with an unlisted indicator `[Akses Terbatas]` and list it in the dropdown with a direct access badge (per D-07).
- If all workshops are inactive, `CourseSwitcher` must remain clickable with "Beranda Kursus" as active and display a disabled item note "Tidak ada workshop aktif saat ini" with id `course-dropdown-empty-note` (per D-08).
- Admin updates in `AdminCourseManagementView.tsx` must trigger `router.invalidate()` and broadcast `learnwith:course_status_changed` (per D-13).
- `__root.tsx` must listen to `learnwith:course_status_changed` and call `router.invalidate()` (per D-14).
- Both `assets/css/components.css` and `public/assets/css/components.css` must remain 100% byte-for-byte identical.

### Artifacts
- Registry: `COURSE_NAV_REGISTRY` in `app/data/courses.ts`
- Utility: `app/utils/courseBroadcast.ts` exporting `broadcastCourseStatusChange` and `COURSE_STATUS_BROADCAST_CHANNEL`
- Modified Components: `AdminCourseManagementView.tsx`, `__root.tsx`, `Header.tsx`, `CourseSwitcher.tsx`
- Styles: Mirrored CSS for `.switcher-unlisted-badge`, `.switcher-empty-note` in `assets/css/components.css` and `public/assets/css/components.css`

### Key Links
- `AdminCourseManagementView.tsx` calls `broadcastCourseStatusChange(courseId, targetStatus)` and `router.invalidate()`.
- `__root.tsx` loader calls `getPublicCourseStatusesFn()`; `useEffect` listens on `BroadcastChannel` to invoke `router.invalidate()`.
- `Header.tsx` receives `courseStatuses` from `__root.tsx` and passes it to `CourseSwitcher.tsx`.
- `CourseSwitcher.tsx` resolves menu options from `COURSE_NAV_REGISTRY` matched against `courseStatuses`.

### Prohibitions
- DO NOT hardcode course navigation items inside `CourseSwitcher.tsx`; use `COURSE_NAV_REGISTRY`.
- DO NOT display hidden courses in the switcher dropdown to users visiting the home page or other courses; only show a hidden course if the user is currently on that course's URL (per D-07).
- DO NOT disable the switcher button entirely when all courses are inactive; keep it clickable to allow returning to "Beranda Kursus" (per D-08).
</must_haves>

           useEffect(() => {
             if (typeof window === 'undefined' || !('BroadcastChannel' in window)) return
             const channel = new BroadcastChannel(COURSE_STATUS_BROADCAST_CHANNEL)
             channel.onmessage = (event) => {
               if (event.data?.type === 'STATUS_UPDATED') {
                 router.invalidate()
               }
             }
             return () => {
               channel.close()
             }
           }, [router])
