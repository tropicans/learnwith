<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Paste / Input Textarea → Component State | Participant inputs sensitive terminal logs and bot tokens into browser memory. |
| Sanitized Text State → Clipboard API | User copies sanitized log output to OS clipboard for sharing in chat. |
| Search Input Query → DOM Card Rendering | Unsanitized search queries passed into React state for item filtering. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-04 | Information Disclosure | `PretrainingRedactionSection.tsx` | Critical | mitigate | Copy button (`#btn-copy-redacted`) strictly reads from `outputText` (the output of `sanitizeLogText`), never from `inputText`. Display warning toast if output is empty. |
| T-27-05 | Cross-Site Scripting | `PretrainingTroubleshootingSection.tsx` | High | mitigate | Ensure search queries and card texts are rendered exclusively through standard JSX curly-brace expressions (`{item.title}`, `{step}`) with automatic React escaping; never use `dangerouslySetInnerHTML`. |
| T-27-06 | Information Disclosure | `PretrainingRedactionSection.tsx` | Medium | mitigate | Redacted output textarea has `readOnly={true}` attribute to prevent accidental user typing that could disrupt sanitized tokens. |
</threat_model>
