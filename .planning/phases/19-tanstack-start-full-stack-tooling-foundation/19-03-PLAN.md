  <read_first>.planning/phases/19-tanstack-start-full-stack-tooling-foundation/19-RESEARCH.md, .planning/phases/19-tanstack-start-full-stack-tooling-foundation/19-PATTERNS.md</read_first>
  <action>
    1. Create `Dockerfile` honoring locked decisions D-10 and D-16:
       - Multi-stage build targeting `node:20-alpine`:
         - Stage 1 (`builder`):
           - `WORKDIR /app`
           - `COPY package*.json ./`
           - `COPY tests/package.json ./tests/`
           - `COPY assets/package.json ./assets/`
           - `RUN npm ci`
           - `COPY . .`
           - `RUN npm run build`
           - `RUN npm run typecheck`
         - Stage 2 (`runner`):
           - `WORKDIR /app`
           - `ENV NODE_ENV=production`
           - `ENV PORT=3173`
           - `ENV HOST=0.0.0.0`
           - `COPY --from=builder /app/.output ./.output`
           - `COPY --from=builder /app/public ./public`
           - `EXPOSE 3173`
           - `CMD ["node", ".output/server/index.mjs"]`
    2. Create `docker-compose.yml` honoring locked decision D-10:
       ```yaml
       services:
         learnwith:
           build:
             context: .
             dockerfile: Dockerfile
           container_name: learnwith-app
           restart: unless-stopped
           ports:
             - "3173:3173"
           environment:
             - NODE_ENV=production
             - PORT=3173
             - HOST=0.0.0.0
       ```
    3. Create `.dockerignore` preventing unnecessary build context bloat:
       ```
       node_modules
       .git
       .output
       .vinxi
       graphify-out
       scratch
       *.docx
       ```
  </action>

<threat_model>
| Threat Ref / Vector | Risk Description | Mitigation | Acceptance Gate |
|---|---|---|---|
| Port Collision | Hardcoding standard port 3000/5173 causes failure when other local servers are active | Bind explicitly to Port 3173 in `Dockerfile` (`ENV PORT=3173`, `EXPOSE 3173`) and `docker-compose.yml` (`3173:3173`) | Port 3173 responds to HTTP SSR requests |
| Container Context Bloat | Copying unignored `node_modules`, large `.docx` files, or `.git` into build context drastically slows down build | Exhaustive `.dockerignore` excluding `node_modules`, `.output`, `.vinxi`, `*.docx`, `scratch/` | Build context is minimal (< 50MB before npm ci) and builds under 60 seconds |
| Production Runtime Crash | Missing server output artifacts or incomplete bundle copying in runner stage | Builder stage executes `npm run build` and `npm run typecheck`, runner stage copies `.output` and `public` | Container runs `node .output/server/index.mjs` without missing file runtime exceptions |
</threat_model>
