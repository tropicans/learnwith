<objective>
Implement Content Security Policy (CSP) protection, iframe frame-busting (anti-clickjacking), and a comprehensive DOM sanitization audit to complete Milestone v2.2.

Purpose: Prevent unauthorized script execution, clickjacking in malicious iframes, and DOM-based XSS vectors.
Output: Strict CSP in <head>, frame-busting guard, DOM escapeHtml sanitizer, unit test suite (tests/csp-dom-security.test.js), and E2E Playwright suite (scratch/test_phase18_security.py).
</objective>

<tasks>

1. **Task 18-01-01: Content Security Policy (SEC-07)**
   - Add strict CSP meta tag to `<head>` in `index.html`.
   - Allow supported assets: `'self'`, Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`), image `data:`/`blob:`, disallow unrestricted external scripts.

2. **Task 18-01-02: Anti-Clickjacking & Frame-Busting Guard (SEC-08)**
   - Add early frame-busting guard in `<head>` of `index.html` that inspects `window.top !== window.self`.
   - Mitigates clickjacking or hidden iframe manipulation.

3. **Task 18-01-03: DOM Input Sanitization Audit & escapeHtml (SEC-09)**
   - Implement `escapeHtml()` sanitization utility in `assets/js/app.js`.
   - Audit all dynamic DOM insertions (quiz score banner, certificates, report previews) to guarantee 0% DOM XSS vulnerabilities.

</tasks>
