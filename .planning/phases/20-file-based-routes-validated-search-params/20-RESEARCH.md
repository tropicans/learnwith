## Executive Summary

Phase 20 implements the declarative, type-safe file-based routing architecture and validated search params layer for LearnWith using `@tanstack/react-router` and `zod` on top of the TanStack Start and Vinxi foundation established in Phase 19.

Currently, `learnwith` relies on a single monolithic `index.html` file (7,400+ lines) where views (`#container-home`, `#container-course-ai`, `#container-course-word`), session modes (`pretraining`, `live-class`), and interactive filters are toggled via imperative DOM manipulation (`element.style.display`, class mutations, and raw `window.location.search` manipulation in `assets/js/app.js`).

Phase 20 maps these views into idiomatic, modern file-based routes:
1. **Root Document Route (`app/routes/__root.tsx`) [ROUTE-01]**:
   - Enhances the shell created in Phase 19 into a complete document layout with `<Meta />`, `<Links />`, `<Outlet />`, `<Scripts />`, and `<ScrollRestoration />`.
   - Incorporates existing platform stylesheet assets (`assets/css/main.css`, `assets/css/components.css`, Google Fonts) and global platform shell components (Header, Brand Logo, Course Selector Pill, Global Search Bar placeholder).
2. **Index Route (`app/routes/index.tsx`) [ROUTE-02]**:
   - Maps the Google NotebookLM-style Frontpage Hub / Workshop Gallery (`#container-home`).
   - Renders platform welcome hero, filter chips (`all`, `ai`, `word`), and notebook cards (`Hands-on Agentic AI`, `Pengolahan Kata ASN`, `Standar Dokumen BPSDM`).
3. **Course AI Nested / File Route (`app/routes/course.ai.tsx`) [ROUTE-03]**:
   - Maps the Agentic AI Workshop workspace (`#container-course-ai`).
   - Hosts dual-mode session navigation (`pretraining` vs `live-class`) and provides the curriculum outline and interactive modules.
4. **Course Word Nested / File Route (`app/routes/course.word.tsx`) [ROUTE-04]**:
   - Maps the Pengolahan Kata Tingkat Lanjut workspace (`#container-course-word`).
   - Incorporates gate protection / passcode prompt modal integration and provides module navigation (Bab I - Bab V).
5. **Type-Safe Zod Search Parameters Schema [ROUTE-05]**:
   - Defines and validates search parameters via TanStack Router's `validateSearch: zodSearchValidator(schema)`.
   - Validates `mode` (`pretraining` | `live-class`), `tab`, `filter` (`all` | `ai` | `word`), `unlock`, and `checkpoint`.
   - Ensures end-to-end type safety when creating links (`<Link to="/course/ai" search={{ mode: 'live-class' }} />`) and using `useSearch()`.

## Technical Validation & Traps to Avoid

1. **Vite / Vinxi Route Generation Synchronization**:
   - TanStack Router generates `app/routeTree.gen.ts`.
   - When new route files are created (`app/routes/course.ai.tsx`, `app/routes/course.word.tsx`), Vinxi dev/build automatically regenerates `routeTree.gen.ts`.
   - Ensure imports and file conventions match TanStack Router v1 exact syntax (`export const Route = createFileRoute('/path')({ ... })`).
2. **Search Params Validation with Zod in TanStack Router**:
   - In TanStack Router 1.120.x, route search params validation can be written using zod parser:
     ```ts
     import { z } from 'zod';
     const searchSchema = z.object({
       mode: z.enum(['pretraining', 'live-class']).catch('pretraining'),
       filter: z.enum(['all', 'ai', 'word']).catch('all'),
     });
     export const Route = createFileRoute('/course/ai')({
       validateSearch: (search) => searchSchema.parse(search),
       // ...
     });
     ```
   - Using `.catch()` ensures invalid user URL tampering gracefully falls back to default values without crashing the route.
3. **SSR Safety & Zero-FOUC (Flash of Unstyled Content)**:
   - Root document route `__root.tsx` must link stylesheets in `head`:
     ```ts
     head: () => ({
       links: [
         { rel: 'stylesheet', href: '/assets/css/main.css' },
         { rel: 'stylesheet', href: '/assets/css/components.css' },
       ]
     })
     ```
   - Legacy assets in `assets/` can be served directly or referenced via public path mapping.
4. **Preserving Legacy Test Suite & Backward Compatibility**:
   - The legacy `index.html` and `assets/js/*.js` test files remain untouched and intact in the repository so `npm test` runs with 11/11 tests passing.
   - All TypeScript compilation must pass `npm run typecheck` (`tsc --noEmit`).
