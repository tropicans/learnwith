<task type="auto" id="29-01-03">
<title>Implement Admin Session & Cookie Management</title>
<instruction>
Create `app/server/session.ts`:
- Session cookie name: `learnwith_admin_session`.
- Session token generation using `crypto.randomBytes(32).toString('hex')`.
- In-memory session registry with timestamp and TTL (24 hours).
- `createAdminSession()`: generates token, records creation time and authMethod, returns token.
- `validateAdminSession(token: string)`: checks token presence in registry, checks TTL, returns session data or null.
- `revokeAdminSession(token: string)`: removes token from registry.
- `setSessionCookie(token: string)`: uses TanStack Start / Nitro header primitives (`setResponseHeader`) with `HttpOnly`, `SameSite=Lax`, `Path=/`, `Max-Age=86400`, and `Secure` (when in production).
- `clearSessionCookie()`: clears the cookie via `Max-Age=0`.
- `readSessionToken()`: extracts session token from `getRequestHeader('cookie')`.
</instruction>
<files>app/server/session.ts</files>
</task>

<task type="auto" id="29-01-04">
<title>Implement Admin Server Functions</title>
<instruction>
Create `app/server/adminAuth.ts` exporting TanStack Start server functions using `createServerFn`:
- `adminLoginFn`: POST method, validated by `adminLoginInputSchema`. Verifies candidate passkey with `verifyAdminPasskey()`. If valid, creates session, calls `setSessionCookie()`, returns success. If invalid, returns `success: false` with descriptive error.
- `adminCheckSessionFn`: GET method. Reads session token via `readSessionToken()`, validates via `validateAdminSession()`. Returns `{ authenticated: boolean, adminUser?: ... }`.
- `adminLogoutFn`: POST method. Reads token, revokes session, calls `clearSessionCookie()`, returns `{ success: true }`.
- `adminGetAuthConfigFn`: GET method. Returns public OAuth configuration state without exposing secrets.
</instruction>

</task>
