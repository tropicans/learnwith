<threat_model>
## Trust Boundaries
- User inputs in report fields (name, OS, problem step, raw error message) are untrusted strings.
- Local storage (`learnwith_ai_state_v1`) holds participant state.
- Output text is copied to clipboard or previewed in DOM.

## Threat Analysis
- **Token / Credential Leakage in Reports**: Raw error logs pasted by participants might contain Telegram bot tokens, OpenAI keys, or Windows paths.
  - *Mitigation*: Run `sanitizeLogText` on error message before incorporating it into the final report text.
- **State Pollution Across Courses**: Editing participant info must never touch `learnwith_word_state_v1` or Course 2 Word checkpoints.
  - *Mitigation*: Strict namespace isolation in `usePretrainingState.ts` and automated test asserting multi-course isolation.
- **ReDoS / Injection via Malformed Strings**: Participant names or Telegram handles with excessive `@` or control characters.
  - *Mitigation*: Safe regex replace (`replace(/^@+/, '')`) and standard string trimming.
</threat_model>
