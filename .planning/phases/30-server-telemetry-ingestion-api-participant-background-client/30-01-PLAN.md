<task type="auto" id="30-01-01">
<title>Define Telemetry Validation Schemas</title>
<instruction>
Create `app/schemas/telemetry.ts` using Zod:
- `participantTelemetrySchema`: object with `participantId` (string 1..64), `name` (string, default 'Peserta'), `agency` (string, default '-'), `courseId` ('ai' | 'word'), `progressPercent` (number 0..100), `completedTasks` (min 0), `totalTasks` (min 1), `checkpoints` (record of 'pending' | 'passed' | 'failed'), `readinessStatus` ('ready' | 'clinic' | 'pending'), optional `quizScore` (0..100), `clientTimestamp` (number).
- `telemetryIngestResultSchema`: object with `success` (boolean), `receivedAt` (number), `participantId` (string).
- `telemetryQueryFilterSchema`: object with `courseId` ('all' | 'ai' | 'word'), `readiness` ('all' | 'ready' | 'clinic' | 'pending'), optional `search` (string).
- `telemetryDashboardStatsSchema`: object with `totalParticipants`, `activeParticipants`, `checkpointCompletionRate`, `averageQuizScore`, `readyRatio`, `clinicRatio`.
- `participantRecordSchema`: extends telemetry schema with `serverReceivedAt` and `lastActiveAt`.
Export all inferred TypeScript types.
</instruction>

<task type="auto" id="30-01-02">
<title>Implement In-Memory Telemetry Store</title>
<instruction>
Create `app/server/telemetryStore.ts`:
- Store map: `Map<string, ParticipantRecord>`.
- `ingestTelemetry(input: ParticipantTelemetryInput): ParticipantRecord`: saves or updates participant by `participantId`, updates `lastActiveAt: Date.now()`.
- `getParticipants(filter?: TelemetryQueryFilter): ParticipantRecord[]`: returns array of records sorted by `lastActiveAt` descending, filtered by `courseId`, `readiness`, and case-insensitive text match on `name` or `agency`.
- `getParticipantById(id: string): ParticipantRecord | null`.
- `getTelemetryStats(): TelemetryDashboardStats`: computes aggregate metrics across all stored participants.
- `initSeedDataIfEmpty()`: populates store with realistic sample participants (e.g. 12 ASN across various agencies) for immediate offline demo capability.
- `clearTelemetryStoreForTesting()`: resets store for automated unit tests.
</instruction>
<files>app/server/telemetryStore.ts</files>
</task>

<task type="auto" id="30-01-03">
<title>Implement Server Functions for Telemetry</title>
<instruction>
Create `app/server/telemetry.ts`:
- `ingestParticipantTelemetryFn`: TanStack Start `createServerFn({ method: 'POST' })` validating input with `participantTelemetrySchema`. Calls `ingestTelemetry()` on store and returns `TelemetryIngestResult`.
- `getParticipantTelemetryListFn`: TanStack Start `createServerFn({ method: 'GET' })` with optional query validator `telemetryQueryFilterSchema`. Returns `{ participants: ParticipantRecord[], stats: TelemetryDashboardStats }`.
</instruction>
