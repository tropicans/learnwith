<instruction>
Create `app/utils/telemetryClient.ts`:

- `sendParticipantTelemetry(payload: Omit<ParticipantTelemetryInput, 'participantId' | 'clientTimestamp'>)`:
  - Injects `participantId` and `clientTimestamp: Date.now()`.
  - Implements debounce (e.g., 500ms) to coalesce rapid checklist interactions.
  - Calls `ingestParticipantTelemetryFn({ data: fullPayload })`.
  - Wraps execution in `try / catch`, logging to debug console only, preventing any thrown errors or unhandled promise rejections.
- Export `flushTelemetryImmediately()` for testing and checkpoint completion events.
