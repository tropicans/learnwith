<title>Troubleshooting Schema, Sanitized Ingestion Store & Auto-Classification Engine</title>
<instruction>
Build the data schemas, server store, auto-classification engine, and RPC functions for troubleshooting logs:

1. Create `app/schemas/troubleshooting.ts`:
   - Define and export Zod schemas and TypeScript interfaces:
     - `troubleshootingCategorySchema`: `z.enum(['port_conflict', 'powershell_policy', 'oauth_api_key', 'telegram_conflict', 'permissions_eperm', 'network_runtime', 'other'])`.
     - `troubleshootingSeveritySchema`: `z.enum(['low', 'medium', 'high', 'critical'])`.
     - `troubleshootingStatusSchema`: `z.enum(['open', 'investigating', 'resolved'])`.
     - `troubleshootingLogRecordSchema`:
       - `id`: `z.string()`.
       - `timestamp`: `z.number()`.
       - `participantId`: `z.string()`.
       - `participantName`: `z.string().optional()`.
       - `courseId`: `z.enum(['ai', 'word', 'system'])`.
       - `category`: `troubleshootingCategorySchema`.
       - `severity`: `troubleshootingSeveritySchema`.
       - `rawErrorText`: `z.string()` (always sanitized).
       - `problemStep`: `z.string().optional()`.
       - `os`: `z.string().optional()`.
       - `status`: `troubleshootingStatusSchema`.
       - `suggestedCommand`: `z.string().optional()`.
       - `suggestedRemediation`: `z.string().optional()`.
       - `instructorNotes`: `z.string().optional()`.
       - `resolvedAt`: `z.number().optional()`.
     - `ingestTroubleshootingInputSchema`:
       - `participantId`: `z.string().min(1)`.
       - `participantName`: `z.string().optional()`.
       - `courseId`: `z.enum(['ai', 'word', 'system']).default('ai')`.
       - `errorMsg`: `z.string().min(3).max(5000)`.
       - `problemStep`: `z.string().max(200).optional()`.
       - `os`: `z.string().max(100).optional()`.
     - `troubleshootingFilterSchema`:
       - `category`: `z.enum(['all', 'port_conflict', 'powershell_policy', 'oauth_api_key', 'telegram_conflict', 'permissions_eperm', 'network_runtime', 'other']).default('all')`.
       - `severity`: `z.enum(['all', 'low', 'medium', 'high', 'critical']).default('all')`.
       - `status`: `z.enum(['all', 'open', 'investigating', 'resolved']).default('all')`.
       - `courseId`: `z.enum(['all', 'ai', 'word', 'system']).default('all')`.
       - `search`: `z.string().optional()`.
       - `limit`: `z.number().default(100)`.
     - `troubleshootingStatsSchema`:
       - `totalIncidents`: `z.number()`.
       - `categoryCounts`: `z.record(z.string(), z.number())`.
       - `openCount`: `z.number()`.
       - `investigatingCount`: `z.number()`.
       - `resolvedCount`: `z.number()`.
       - `topCategory`: `z.string()`.
     - `updateTroubleshootingStatusSchema`:
       - `id`: `z.string()`.
       - `status`: `troubleshootingStatusSchema`.
       - `instructorNotes`: `z.string().max(1000).optional()`.

2. Create `app/server/troubleshootingStore.ts`:
   - Import `sanitizeLogText` from `../utils/redaction.ts` for dual-layer redaction (T-32-04).
   - Implement classification rule engine `classifyErrorLog(errorText: string)`:
     - `port_conflict`: Matches `/(?:20128|EADDRINUSE|address already in use|listen EADDRINUSE)/i`.
       - Severity: `'high'`.
       - Suggested command: `Stop-Process -Id (Get-NetTCPConnection -LocalPort 20128).OwningProcess -Force`.
       - Remediation: `Port 20128 digunakan proses lain. Hentikan proses yang memblokir port lalu jalankan ulang 9Router.`.
     - `powershell_policy`: Matches `/(?:Execution_Policies|running scripts is disabled|PSScriptRoot|Set-ExecutionPolicy|restricted)/i`.
       - Severity: `'medium'`.
       - Suggested command: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`.
       - Remediation: `PowerShell memblokir eksekusi skrip otomatis. Ubah kebijakan eksekusi untuk sesi terminal saat ini.`.
     - `oauth_api_key`: Matches `/(?:401 Unauthorized|Invalid API Key|GOOGLE_CLIENT_ID|AIza|unauthorized_client|gemini)/i`.
       - Severity: `'critical'`.
       - Suggested command: `Check API Key in 9Router config or re-issue in Google Cloud Console`.
       - Remediation: `Kredensial Google OAuth atau Gemini API Key tidak valid. Verifikasi kunci di console pengembang.`.
     - `telegram_conflict`: Matches `/(?:409 Conflict|getUpdates|terminated by other|hermes gateway)/i`.
       - Severity: `'medium'`.
       - Suggested command: `hermes gateway stop; hermes gateway start`.
       - Remediation: `Bot Telegram aktif di tempat lain atau polling bertabrakan. Hentikan instance kembar dan restart gateway.`.
     - `permissions_eperm`: Matches `/(?:EPERM|Access denied|Permission denied|operation not permitted)/i`.
       - Severity: `'high'`.
       - Suggested command: `Start-Process powershell -Verb RunAs`.
       - Remediation: `Hak akses Administrator diperlukan untuk menulis ke direktori program atau menginstal paket global.`.
     - `network_runtime`: Matches `/(?:ETIMEDOUT|ENOTFOUND|ECONNREFUSED|fetch failed|socket hang up)/i`.
       - Severity: `'medium'`.
       - Suggested command: `Test-NetConnection -ComputerName generativelanguage.googleapis.com -Port 443`.
       - Remediation: `Koneksi jaringan terputus atau proxy instansi memblokir panggilan API. Uji konektivitas gateway.`.
     - Fallback `other`:
       - Severity: `'low'`.
       - Remediation: `Kendala umum di luar kategori terdefinisi. Periksa detail log terminal untuk analisis manual.`.
   - Seed store with 6 representative classroom incident logs (1 port conflict, 1 powershell, 1 oauth, 1 telegram, 1 eperm, 1 resolved network issue) so instructors have realistic initial data upon inspection.
   - Implement storage methods:
     - `ingestTroubleshootingLog(input: IngestTroubleshootingInput): TroubleshootingLogRecord`:
       - Applies `sanitizeLogText(input.errorMsg)` to redact any secret tokens before saving.
       - Runs `classifyErrorLog()` on sanitized error text.
       - Stores incident record with `status: 'open'` and timestamp.
       - Returns record.
     - `getTroubleshootingLogs(filter?: TroubleshootingFilter): TroubleshootingLogRecord[]`:
       - Filters records by category, severity, status, courseId, and text search across error text, participant name, and ID.
       - Returns sorted by timestamp descending.
     - `getTroubleshootingStats(): TroubleshootingStats`:
       - Aggregates total incidents, category counts, open/investigating/resolved counts, and identifies the most frequent error category.
     - `updateTroubleshootingStatus(input: UpdateTroubleshootingStatusInput): TroubleshootingLogRecord | null`:
       - Updates status, instructor notes, and sets `resolvedAt` timestamp if marked `'resolved'`.
     - `clearTroubleshootingStoreForTesting()`: Resets store state for test suites.

3. Create `app/server/troubleshooting.ts`:
   - Implement `ingestTroubleshootingLogFn = createServerFn({ method: 'POST' })`:
     - Validator: `ingestTroubleshootingInputSchema.parse(data)`.
     - Ingests sanitized log into store.
     - Returns `{ success: true, id: record.id, category: record.category }`.
   - Implement `getTroubleshootingLogsFn = createServerFn({ method: 'GET' })`:
     - Protected: validates active admin session via `readSessionToken()` & `validateAdminSession()`.
     - Returns `{ logs: getTroubleshootingLogs(filter), stats: getTroubleshootingStats() }`.
   - Implement `updateTroubleshootingLogStatusFn = createServerFn({ method: 'POST' })`:
     - Protected: validates active admin session.
     - Validator: `updateTroubleshootingStatusSchema.parse(data)`.
     - Updates record in store.
     - Returns `{ success: true, record }`.
</instruction>
