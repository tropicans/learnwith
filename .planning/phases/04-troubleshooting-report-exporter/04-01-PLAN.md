# Plan 04-01: Interactive Troubleshooting Hub & Sensitive Data Redaction Tool

## Goal
Implement a searchable and categorizable Troubleshooting Knowledge Base (Section 12 of guide) and an interactive regex-driven Redaction Tool (Section 13) to protect participant tokens before sharing logs.

## Requirements
- **TRBL-01**: Search & category filtering for common setup issues (PowerShell policy, PATH reload, port collision, token leak).
- **TRBL-02**: Step-by-step resolution cards with 1-click copy code snippets for fixes.
- **TRBL-03**: Interactive Token & Secret Redaction tool detecting and masking API keys, bot tokens, and personal credentials.

## Proposed Changes

### 1. `index.html`
- Add Section `#sec-troubleshooting`:
  - Search input with category filter pill tabs (`all`, `node`, `router`, `telegram`).
  - 10 step-by-step resolution cards from Section 12 with syntax-highlighted commands and 1-click copy.
- Add Section `#sec-redaction`:
  - Interactive Redaction Helper Card.
  - Raw log `<textarea>` with placeholder.
  - Instant "Sensor Log" trigger & debounced live sanitization.
  - Output `<textarea>` with copy button and badge displaying number of sanitized tokens.

### 2. `assets/css/components.css`
- Filter pill button styles (`.troubleshoot-filter-btn.active`).
- Troubleshooting card layout (`.trouble-card`, `.trouble-meta`, `.trouble-solution`).
- Redaction workbench styling (`.redaction-grid`, `.redaction-box`, `.redaction-count-badge`).

### 3. `assets/js/app.js`
- `setupTroubleshootingHub()`: Category filter filtering, keyword search matching.
- `setupRedactionTool()`: Regex redaction engine (`REDACTION_RULES`) running on input, counting matches, and writing to sanitized output.

## Verification
- Filter tabs instantly toggle visible troubleshooting cards.
- Pasting a raw token (e.g. `123456789:ABCDefGhIjKlMnOpQrStUvWxYz012345678` or `sk-proj-abc1234567890`) replaces it with `[REDACTED_TELEGRAM_BOT_TOKEN]` / `[REDACTED_API_KEY]`.
- 1-click copy copies the sanitized text with toast confirmation.
