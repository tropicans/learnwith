# Plan 04-02: Form Laporan Kesiapan, 1-Click WhatsApp/Telegram Export, Print/PDF Styling & Tests

## Goal
Implement the pre-filled "Form Laporan Kesiapan" (Section 15 of guide) with dynamic data binding, 1-click WhatsApp/Telegram export, print/PDF styling for offline submission, and automated testing suite.

## Requirements
- **RPT-01**: Pre-filled "Form Laporan Kesiapan" automatically bound to participant input (Name, OS, version, Checkpoints 1-3, Cloud status, error logs).
- **RPT-02**: 1-click copy formatted readiness report ready to paste into WhatsApp / Telegram.
- **RPT-03**: Print and PDF-ready styling (`@media print`) ensures the guide and readiness certificate format cleanly for offline printing or PDF saving.

## Proposed Changes

### 1. `index.html`
- Add Section `#sec-readiness-report`:
  - Participant detail fields (Name, OS selector: Windows 11 / Windows 10, Problematic step input, Error message input with auto-redaction integration).
  - Live formatted report preview box `<pre id="report-output-preview">`.
  - Action buttons:
    - `<button id="btn-copy-report" class="btn btn-success">`: 1-click copy report formatted for WhatsApp/Telegram.
    - `<button id="btn-print-report" class="btn btn-secondary">`: Trigger `window.print()` for print/PDF export.

### 2. `assets/css/components.css`
- Form Laporan layout styling (`.report-workbench`, `.report-preview-box`).
- `@media print` rules:
  - Hide `.app-header`, `.app-sidebar`, `#modal-reset-confirm`, `.floating-search-btn`, `.btn`, `.toast-container`.
  - Force light background and high contrast text on main container.
  - Page-break controls preventing awkward breaks inside cards.

### 3. `assets/js/app.js`
- `setupReadinessReport()`: Live report generator subscribing to `AppState` changes (`stateChange`, `checkpointUpdate`, `participantUpdate`) and form input changes.
- Print trigger handler (`window.print()`).

### 4. `tests/troubleshooting-exporter.test.js`
- Automated test suite testing:
  - Redaction regex rules (Telegram bot tokens, OpenAI keys, emails, user paths).
  - Report formatting generator matching Section 15 template.
  - Troubleshooting category filtering logic.

## Verification
- Modifying participant name or toggling checkpoint immediately updates the live report preview.
- Clicking "Salin Laporan" copies formatted markdown/plain text to clipboard with toast notification.
- Running unit test suite verifies 100% regex sanitization coverage and report formatting.
