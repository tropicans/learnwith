Output: Hardened URL gate parser, tab-scoped session storage with integrity verification, sliding auto-lock timer, automated unit test suite (`tests/session-security.test.js`), and E2E Playwright test (`scratch/test_phase17_security.py`).
</objective>

       - Store `{ unlocked: true, course, unlockedAt, expiresAt, checksum }` where `checksum` is computed using SHA-256 of `(course + expiresAt + seed)`.
       - On session lookup, recompute checksum. If checksum does not match (tampered in DevTools) or `Date.now() > expiresAt`, discard token and treat as locked.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL Query Parameters → App Initialization | Untrusted query strings entering through browser location bar, external links, or phishing attempts. |
| DevTools Console → Storage Engine | Local user attempting to grant unauthorized access by directly modifying `localStorage` or `sessionStorage` values. |
| Inactive Browser Tab → Shared Environment | Unattended physical device in classroom/office leaving sensitive course modules accessible to bystanders. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01 | Elevation of Privilege | `assets/js/app.js` URL parameter parser | Critical | mitigate | Remove `?unlock=dev`, `?unlock=word`, `?unlock=1` unauthenticated bypasses. Require valid SHA-256 hash matching against `allowedPasscodeHashes`. |
| T-17-02 | Information Disclosure | Browser Address Bar & History | High | mitigate | Purge query parameters immediately on boot via `window.history.replaceState`. |
| T-17-03 | Tampering | Web Storage (`localStorage` / `sessionStorage`) | High | mitigate | Partition to `sessionStorage` and protect tokens with in-memory seeded checksums. Tampered tokens fail validation and force lock state. |
| T-17-04 | Elevation of Privilege | Inactive Client Session | High | mitigate | Sliding inactivity watcher automatically expires session and locks modules after 15 minutes of idle time. |
</threat_model>
