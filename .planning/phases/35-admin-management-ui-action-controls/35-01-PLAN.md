# Plan 35-01: Admin Shell Navigation Tab, Course Management View, KPIs & 1-Click Visibility Toggles

## Overview
Implement the foundational administrator user interface for course lifecycle management within the LearnWith Admin Command Center (`/admin`). This plan establishes the navigation integration in `AdminShell.tsx`, the primary container `AdminCourseManagementView.tsx`, the top-level metric counters `CourseLifecycleKPIs.tsx`, and the visual course status cards `CourseStatusCards.tsx` with 1-click visibility toggling (`active` <-> `hidden`) and instant Toast feedback via `showToast`.

All stylesheet modifications to `assets/css/admin.css` are mirrored identically to `public/assets/css/admin.css` in adherence with project security and testing invariants.

## Requirements Covered
- **COURSE-ADMIN-01**: Admin Command Center (`/admin`) features a dedicated "Manajemen Kursus" view/tab in `AdminShell` displaying all courses with their current status badge, metadata, and quick stats.
- **COURSE-ADMIN-02**: Admin can toggle course visibility with 1-click `Tampilkan` (Show) / `Sembunyikan` (Hide) action buttons with instant visual feedback.

## Threat Model (ASVS L1 Compliance)
<threat_model>
- **Threat T-35-01: Unauthorized status mutation via forged client RPC requests**
  - **Attack Surface**: Client-side invocation of `adminUpdateCourseStatusFn`
  - **Severity**: High
  - **Mitigation**: Server-side session verification via `assertAdminAuthorized` is enforced on every call to `adminUpdateCourseStatusFn`. Client retrieves session token via `getClientAdminToken()` and passes it in payload. No sensitive server secrets or private keys are exposed in client components.
- **Threat T-35-02: Race conditions or UI state desynchronization from rapid button clicks**
  - **Attack Surface**: Visibility toggle buttons (`Tampilkan Kursus` / `Sembunyikan Kursus`)
  - **Severity**: Medium
  - **Mitigation**: Mutation actions maintain per-course loading/disabled states (`isMutatingId`) preventing duplicate concurrent submissions while requests are in flight. Successful mutations re-fetch status reactively and display localized feedback via `showToast`.
</threat_model>

## Wave Structure
- **Wave 1**: Automated UI test harness creation (`tests/course-lifecycle-admin-ui.test.js`), `AdminShell.tsx` navigation tab integration, and `AdminCourseManagementView.tsx` container with lifecycle data fetching.
- **Wave 2**: `CourseLifecycleKPIs.tsx`, `CourseStatusCards.tsx` with 1-click visibility toggle, instant Toast feedback, and mirrored CSS styling in `assets/css/admin.css` and `public/assets/css/admin.css`.
