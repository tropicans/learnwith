# Plan 35-02: Status Filter Toolbar, Archive/Restore Controls, Delete Safety Guard Modal & Audit Log

## Overview
Complete the course lifecycle administrative suite by introducing status filtering pills, search capabilities, archive and restore action controls, an accessible audit trail table, and a guarded safety confirmation modal for soft-deactivation. This ensures administrators have full visibility over course catalogs across all states while preventing accidental deletions through a strict two-factor confirmation barrier.

All additions to `assets/css/admin.css` are mirrored identically to `public/assets/css/admin.css`.

## Requirements Covered
- **COURSE-ADMIN-03**: Admin can archive/restore a course with `Arsipkan` (Archive) / `Pulihkan` (Restore) action buttons and dedicated status filter tabs (`Semua`, `Aktif`, `Tersembunyi`, `Diarsipkan`, `Dinonaktifkan`).
- **COURSE-ADMIN-04**: Admin can soft-delete a course with `Hapus` / `Nonaktifkan` trigger that requires explicit user confirmation in a safety modal before deactivation.

## Threat Model (ASVS L1 Compliance)
<threat_model>
- **Threat T-35-03: Accidental or unauthenticated service disruption via course deactivation**
  - **Attack Surface**: Soft-delete deactivation action (`adminUpdateCourseStatusFn` with `targetStatus: 'deleted'`)
  - **Severity**: High
  - **Mitigation**: Two-factor confirmation barrier in `CourseDeleteModal`: the confirmation button (`Ya, Nonaktifkan Kursus`) remains strictly disabled until the administrator types the course ID (e.g. `ai`, `word`) or the explicit confirmation keyword `HAPUS`. Course files and database records are never hard-deleted; status transitions to `deleted` (soft-delete), which can be restored by an administrator at any time.
- **Threat T-35-04: Cross-Site Scripting (XSS) or HTML injection via deactivation reason text**
  - **Attack Surface**: Deactivation reason string entered by user and rendered in status cards and audit trail
  - **Severity**: Medium
  - **Mitigation**: Input length capped at 200 characters (`maxLength={200}`), text rendered safely via React standard JSX escaping without `dangerouslySetInnerHTML`, and validated by Zod schema on server RPC.
</threat_model>

## Wave Structure
- **Wave 1**: Filter Toolbar (`CourseFilterToolbar.tsx`) with status pills and search query, empty state handling, archive/restore controls (`Arsipkan Kursus` / `Pulihkan Kursus`), and Audit Trail Table (`CourseLifecycleAuditTable.tsx`).
- **Wave 2**: Safety confirmation modal (`CourseDeleteModal.tsx`) with typed confirmation barrier, modal integration in `AdminCourseManagementView.tsx`, mirrored CSS styling in `assets/css/admin.css` and `public/assets/css/admin.css`, and automated test validation.
