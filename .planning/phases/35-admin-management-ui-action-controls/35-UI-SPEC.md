| Modal Dismiss CTA | Batalkan Perubahan |

## UI Considerations

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Course status cards grid | ✅ covered | When search or filter yields zero courses, renders the documented 'Tidak Ada Kursus Ditemukan' copy with actionable guidance. |
| loading | Course cards & KPI metrics | ✅ covered | Displays skeleton pulse loading state on cards and KPI stats during initial mount and background RPC refetches. |
| error | View container & action buttons | ✅ covered | Catches RPC rejection and renders danger toast with documented error copy and a 'Segarkan Data' retry action. |
| long-text | Course title & deactivation reason | 🧪 backstop | Course titles and reason notes use word-break: break-word and flex-wrap to prevent card horizontal overflow up to 200 characters. |
| destructive | Soft-delete action trigger & modal | ✅ covered | Accidental clicks prevented by CourseDeleteModal requiring explicit case-insensitive input matching course ID or keyword 'HAPUS'. |
| responsive | Filter toolbar & card actions | ✅ covered | Toolbar wraps flex items and action buttons stack gracefully on mobile viewports (<640px) without clipped boundaries. |
| feedback | 1-Click status mutations | ✅ covered | Dispatches immediate top-level Toast notification ('success' or 'danger') with exact localized transition summary upon mutation completion. |
