Modul 1: Pemeriksaan & Instalasi Node.js

Aplikasi pendukung wajib agar 9Router dapat berjalan di komputer Anda

3 Langkah ▼
A
Periksa Apakah Node.js Sudah Terpasang PowerShell

Buka jendela PowerShell, lalu jalankan perintah berikut untuk memeriksa apakah Node.js🟢 Node.jsAplikasi runtime yang dibutuhkan agar 9Router dapat berjalan. sudah tersedia:

PowerShell 
node --version
✓ Hasil yang benar: v24.x.x atau v22.x.x
💡
Penjelasan Versi:

Jika muncul nomor versi LTS🛡️ LTS (Long Term Support)Versi stabil yang didukung jangka panjang dan paling disarankan. seperti v24... atau v22..., langsung lanjutkan ke Langkah C (Periksa npm). Jika muncul pesan node is not recognized, hal itu wajar jika laptop Anda belum pernah diinstal Node.js; lanjutkan ke Langkah B di bawah ini.

B
Instal Node.js (Jika Belum Tersedia) Hanya jika belum ada

Ikuti langkah-langkah resmi berikut untuk mengunduh dan memasang Node.js pada Windows:

  1. Buka browser (Google Chrome atau Microsoft Edge).
  2. Kunjungi situs resmi: https://nodejs.org
  3. Pilih versi yang bertuliskan LTS, lalu unduh file Windows Installer (.msi) 64-bit / x64.
  4. Buka file installer .msi yang telah selesai diunduh.
  5. Klik Next, centang persetujuan lisensi (Accept), dan gunakan seluruh opsi bawaan (default).
  6. Pastikan opsi npm package manager dan Add to PATH tetap dicentang aktif.
  7. Jika sistem Windows meminta izin hak Administrator (UAC), klik Yes.
  8. Setelah selesai, klik Finish.
  9. Tutup SEMUA jendela PowerShell yang terbuka, lalu buka jendela PowerShell yang baru.
  10. Jalankan kembali node --version dan npm --version untuk memastikan.
⚠️
Perhatian Penting:

Jangan memilih file ZIP atau Source Code. Pastikan selalu menggunakan file installer .msi agar konfigurasi PATH berjalan otomatis.

C
Periksa npm (Node Package Manager) PowerShell

Di jendela PowerShell yang baru, periksa ketersediaan npm📦 npmAlat pengelola paket bawaan Node.js untuk mengunduh 9Router. dengan perintah:

PowerShell 
npm --version
✓ Hasil yang benar: Menampilkan angka versi npm (contoh: 10.x.x atau 9.x.x)

📍 Gerbang Checkpoint 1: Node.js Siap

Target Tahap 1

Tahap ini berhasil jika kedua perintah di atas menampilkan nomor versi:

  • node --version → menampilkan nomor versi
  • npm --version → menampilkan nomor versi

Jika salah satunya gagal atau tidak dikenali, lihat panduan di bagian Solusi Kendala atau hubungi tim technical clinic.

Jika muncul permintaan izin Firewall jaringan publik, batalkan/tutup peringatan tersebut.

Modul 3: Pembuatan Bot Telegram & Telegram User ID

Membuat bot Telegram melalui BotFather resmi, mengamankan token bot, dan mencatat nomor Telegram User ID

5 Langkah ▼
A
Buka Akun Resmi @BotFather di Telegram Aplikasi Telegram

Buka aplikasi Telegram di ponsel atau laptop Anda. Gunakan fitur pencarian untuk menemukan akun resmi pembuat bot Telegram:

  1. Buka aplikasi Telegram di ponsel Anda.
  2. Tekan ikon pencarian (kaca pembesar) di bagian atas.
  3. Cari akun: @BotFather.
  4. PENTING: Pastikan username yang Anda pilih tepat bertuliskan @BotFather dan memiliki tanda centang biru resmi (verified badge) dari Telegram.
  5. Buka ruang percakapan tersebut, lalu tekan tombol Start di bagian bawah layar.
🔗 https://t.me/BotFather
🛡️ Tautan resmi Telegram menuju BotFather🤖 BotFatherAkun resmi dari Telegram (terverifikasi centang biru) yang digunakan untuk membuat dan mengatur bot Telegram baru..
⚠️
Waspada Akun Tiruan / Palsu!

Banyak akun tiruan yang menggunakan nama serupa tanpa centang biru. Jangan pernah berinteraksi dengan akun selain @BotFather yang memiliki lencana centang biru resmi.

B
Buat Bot Baru dengan Perintah /newbot Telegram Chat

Kirim perintah berikut ke ruang percakapan dengan @BotFather:

Perintah Telegram 
/newbot
  1. Setelah mengirim /newbot, BotFather akan meminta Nama Tampilan Bot (Display Name). Ketik nama yang mudah dikenali, contoh: Asisten Jadwal Budi.
  2. BotFather kemudian akan meminta Username Bot. Aturan penulisan username bot:
    • Harus unik di seluruh dunia (belum pernah dipakai orang lain).
    • Tidak boleh memakai spasi.
    • Hanya boleh memakai huruf, angka, dan garis bawah (_).
    • Wajib diakhiri dengan kata bot (contoh: jadwal_budi_2026_bot atau asisten_kalender_bot).
  3. Jika muncul pesan "Sorry, this username is already taken", variasikan username Anda dengan menambahkan angka atau nama Anda sampai diterima.
  4. Jika berhasil, BotFather akan membalas dengan pesan selamat yang berisi tautan ke bot Anda serta Bot Token rahasia.
💡
Privasi Nama & Username:

Nama dan username bot dapat dilihat publik di Telegram. Jangan mencantumkan nomor handphone, alamat email pribadi, atau kata sandi pada nama bot Anda.

C
Simpan Bot Token dengan Aman & Aturan Kerahasiaan Sangat Rahasia

Bot Token🔑 Bot TokenKode rahasia panjang yang memungkinkan aplikasi Hermes Agent mengendalikan bot Telegram Anda secara penuh. terlihat seperti deretan angka dan huruf panjang (contoh: 7123456789:AAFlxyz123...). Token setiap peserta berbeda dan unik.

🛑
DILARANG KERAS MENYEBARKAN BOT TOKEN!

Siapa pun yang mengetahui bot token dapat mengendalikan bot Anda sepenuhnya. Ikuti aturan wajib ini:

  • JANGAN mengirim token ke grup kelas WhatsApp atau Telegram.
  • JANGAN mengambil screenshot layar saat token sedang terlihat.
  • JANGAN menyimpan token di dokumen atau folder bersama (Google Drive umum, dsb.).
  • Biarkan token tetap berada di riwayat percakapan pribadi Anda dengan @BotFather (aman), atau simpan di aplikasi Password Manager pribadi Anda.

Perintah Pencabutan Darurat (Jika Token Bocor):
Jika Anda tidak sengaja mengirimkan atau memperlihatkan bot token kepada orang lain, segera batalkan token tersebut dengan mengirim perintah berikut ke @BotFather:

Perintah Darurat BotFather 
/revoke

Pilih bot Anda, lalu BotFather akan menonaktifkan token lama dan memberikan token baru yang aman.

D
Buka Bot Anda & Tekan Start Telegram Chat

Setelah bot berhasil dibuat di BotFather:

  1. Klik tautan bot yang dikirimkan oleh BotFather (misal: t.me/jadwal_budi_2026_bot).
  2. Ruang obrolan dengan bot baru Anda akan terbuka.
  3. Tekan tombol Start (atau Mulai) di bagian bawah obrolan.
ℹ️
Bot Belum Merespons Adalah Hal Normal!

Setelah menekan Start, bot Anda belum akan membalas pesan. Hal ini sepenuhnya wajar dan normal karena aplikasi Hermes Agent belum dihubungkan ke bot Anda. Penyambungan bot ke Hermes akan dilakukan bersama instruktur saat kelas workshop.

E
Dapatkan Nomor Telegram User ID Anda via @userinfobot Penting

Hermes Agent membutuhkan Telegram User ID🆔 Telegram User IDNomor angka murni permanen pengenal akun Anda agar hanya Anda yang diizinkan mengendalikan bot. Anda untuk sistem keamanan, memastikan hanya Anda sendiri yang berhak memerintah bot untuk mengelola kalender:

  1. Di aplikasi Telegram ponsel Anda, cari akun pembantu: @userinfobot.
  2. Buka percakapan resmi tersebut, atau klik tautan: https://t.me/userinfobot
  3. Tekan tombol Start di bagian bawah layar.
  4. Bot akan langsung menampilkan rincian profil Anda. Cari baris bertuliskan Id atau User ID yang hanya berupa angka (contoh: 123456789).
  5. Catat hanya nomor angka tersebut di catatan pribadi laptop Anda agar siap disalin saat kelas.

Aturan Keamanan @userinfobot:

Jangan pernah mengirim bot token, password, atau kode login kepada @userinfobot. Anda hanya perlu menekan tombol Start dan mencatat nomor ID angka yang ditampilkan.

Pusat Bantuan & Troubleshooting Kendala

Solusi langkah demi langkah untuk kendala teknis umum pada Node.js, 9Router, PowerShell, dan Telegram.

🔍
📟

Pesan: node is not recognized

Node.js & npm
Penyebab: PowerShell belum menemukan program Node.js karena belum terpasang atau belum terbaca di sistem.
  1. Jika Anda belum pernah memasang Node.js, buka kembali Modul 1 dan unduh installer Node.js versi LTS dari situs resmi.
  2. Jika sebelumnya sudah pernah memasang Node.js, jangan langsung menginstal ulang. Lanjutkan ke solusi perbaikan PATH di bawah ini.
🔄

Pesan: npm tidak dikenali / The term 'npm' is not recognized

Node.js & npm
Penyebab: Node.js baru saja diinstal namun variabel PATH pada jendela terminal PowerShell yang sedang aktif belum diperbarui.
  1. Tutup seluruh jendela PowerShell / Windows Terminal (bukan hanya satu tab).
  2. Buka PowerShell baru dan uji coba kembali node --version dan npm --version.
  3. Jika masih belum dikenali, muat ulang variabel PATH secara langsung di PowerShell dengan menyalin perintah resmi berikut:
powershell 
$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
  1. Jalankan kembali node --version dan npm --version. Jika berhasil, restart laptop sebelum workshop agar PATH tersimpan permanen.
🛡️

Pesan: running scripts is disabled on this system

PowerShell Security
Penyebab: Kebijakan keamanan eksekusi script PowerShell Windows membatasi script lokal.
⚠️

Solusi Paling Aman: Jangan mengubah pengaturan keamanan PowerShell laptop Anda! Gunakan Command Prompt (cmd.exe) bawaan Windows.

  1. Tutup PowerShell.
  2. Klik tombol Windows / Start, ketik Command Prompt, lalu buka aplikasinya.
  3. Uji dengan mengetik npm --version.
  4. Jalankan instalasi 9Router langsung di Command Prompt:
    cmd 
    npm install -g 9router
  5. Setelah instalasi selesai, jalankan 9router.
🚀

Pesan: 9router tidak dikenali

9Router
Penyebab: Perintah instalasi global npm belum termuat ke sesi terminal aktif.
  1. Tutup jendela PowerShell.
  2. Buka PowerShell baru dan coba ketik 9router kembali.
  3. Jika masih gagal, salin dan gunakan alat Sensor Log untuk menyensor pesan error sebelum mengirimkannya ke instruktur.
🌐

Browser tidak dapat menampilkan dashboard (localhost:20128)

9Router & Port
Penyebab: Terminal 9Router tertutup atau browser menggunakan protokol HTTPS.
  1. Pastikan jendela terminal tempat Anda menjalankan 9router masih terbuka dan menampilkan log aktif.
  2. Tunggu sekitar 15–30 detik agar service internal selesai bersiap.
  3. Buka browser dan ketik alamat secara manual: http://localhost:20128.
  4. Jika belum terbuka, coba alamat alternatif IP loopback: http://127.0.0.1:20128.
  5. PENTING: Pastikan Anda tidak menggunakan https:// karena service lokal menggunakan protokol HTTP biasa.
⏳

Proses instalasi terlihat berhenti / macet

Koneksi & npm
Penyebab: Proses pengunduhan paket npm memerlukan waktu bergantung pada kestabilan koneksi internet.
  1. Tunggu hingga maksimal 10 menit tanpa menutup terminal.
  2. Jika setelah 10 menit tidak ada kemajuan, ambil tangkapan layar (screenshot) hanya pada bagian error terminal saja.
  3. Pastikan tidak ada token, kata sandi, atau nama folder akun pribadi yang tampak pada tangkapan layar tersebut.
🛑

Muncul pesan Access denied, Permission denied, atau EPERM

Hak Akses Windows
Penyebab: Pengguna biasa tidak memiliki izin menulis di folder modul global Windows.
  1. Tutup seluruh jendela PowerShell.
  2. Klik tombol Start / Windows, lalu ketik PowerShell.
  3. Klik kanan pada ikon Windows PowerShell, lalu pilih Run as administrator.
  4. Pilih Yes saat muncul dialog konfirmasi User Account Control (UAC).
  5. Jalankan perintah instalasi: npm install -g 9router.
  6. Setelah instalasi berhasil, segera tutup jendela PowerShell administrator tersebut demi keamanan.
🤖

Username bot sudah digunakan orang lain

Telegram
Penyebab: Username bot di Telegram bersifat global dan unik di seluruh dunia.
  1. Tambahkan inisial nama Anda, tahun, atau angka unik (contoh: jadwal_budi_2026_bot atau budi_asisten_v1_bot).
  2. Pastikan nama akhiran tetap berupa bot atau _bot.
💬

Bot Telegram tidak membalas saat dikirimi pesan

Informasi Normal
Penjelasan: Hal ini sepenuhnya normal pada tahap pre-training!

Bot baru hanya berupa wadah komunikasi kosong. Otak cerdas (Hermes Agent) baru akan dikonfigurasi dan dihubungkan secara langsung saat sesi workshop berlangsung.

Bot token tidak sengaja terkirim ke grup / orang lain

Tindakan Cepat
Bahaya: Siapapun yang memegang bot token dapat mengontrol bot dan membaca pesan.
  1. Segera buka obrolan dengan @BotFather di Telegram.
  2. Kirim perintah: /revoke.
  3. Pilih bot yang tokennya sempat terkirim.
  4. BotFather akan membatalkan token lama dan memberikan bot token baru.
  5. Simpan token baru secara rahasia dan jangan gunakan token lama lagi.

Standar Tata Naskah Dinas Pemprov DKI Jakarta

              
Pedoman tipografi, margin kertas dinas, dan tata kelola kerahasiaan data aparatur berdasar Pergub DKI Jakarta No. 14 Tahun 2020.

            

          

        


        

          
          

            

              📐
              

                Standar Margin Kertas Kedinasan
              

            

            

              Berdasarkan Pergub DKI Jakarta No. 14/2020 tentang Tata Naskah Dinas, format margin halaman naskah dinas resmi (A4 / F4) adalah:
            

            

              
• Margin Atas: 4 cm (ruang kepala surat / logo)

              
• Margin Kiri: 4 cm (ruang penjilidan / perforator)

              
• Margin Bawah: 3 cm (ruang kaki halaman / paraf)

              
• Margin Kanan: 3 cm

            

          


          
          

            

              🔤
              

                Standar Tipografi & Spasi Paragraf
              

            

            

              Ketentuan jenis huruf dan perataan teks naskah dinas untuk memastikan keterbacaan tinggi dan kerapian resmi:
            

            

              
• Font Resmi: Bookman Old Style atau Arial

              
• Ukuran Font Isi: 12 pt (Teks normal / paragraf isi)

              
• Spasi Baris: 1.5 Lines (atau 1.0/1.15 sesuai bentuk naskah)

              
• Perataan Teks: Justify (Rata Kiri-Kanan) dengan pemenggalan kata rapi

            

          


          
          

            

              🛡️
              

                Keamanan Data & Privasi ASN
              

            

            

              Kepatuhan terhadap UU Perlindungan Data Pribadi (UU PDP) dan etika aparatur sipil negara:
            

            

              
• Dilarang: Mengunggah draft dokumen rahasia/internal ke alat konversi online publik.

              
• Wajib Redaksi: Samarkan NIP, NIK, dan nomor telepon riil saat latihan/tangkapan layar.

              
• Pembersihan Metadata: Selalu lakukan Inspect Document sebelum mendistribusikan berkas.

Penguasaan hierarki Styles (Heading 1–3 vs Normal), Navigation Pane, Multilevel List, dan Table of Contents otomatis.

              

            

            

              8 Langkah Praktik
              ▼
            

          


          

            
            

              
A

              

                Penerapan Hierarki Styles (Heading 1–3 vs Normal)
                Home > Styles
              

              

                Buka salinan berkas 01_Dokumen_Berantakan.docx. Jangan membuat judul hanya dengan memperbesar ukuran huruf dan menebalkannya secara manual (manual formatting). Terapkan style Heading 1 untuk judul BAB utama, Heading 2 untuk Subbab, dan Heading 3 untuk anak subbab. Paragraf isi harus menggunakan style Normal.
              


              

                
💡

                

                  
Aturan Emas Hierarki Dokumen ASN:

                  

                    Hierarki yang baik tidak boleh melompati tingkatan. Jangan pernah menggunakan Heading 3 langsung di bawah Heading 1 tanpa ada Heading 2 di antaranya. Word membaca struktur ini untuk Navigation Pane, daftar isi, dan pembaca layar (screen reader).
                  

                

              


              

              
            


            
            

              
B

              

                Modifikasi Style Sesuai Standar Kedinasan
                Right-Click Style > Modify
              

              

                Keseragaman tampilan di seluruh dokumen harus dikendalikan dari Style, bukan diedit per baris teks. Modifikasi style Normal dan Heading 1 agar mematuhi standar Pergub DKI Jakarta No. 14/2020:
              

              
    
                
  1. Pada tab Home galeri Styles, klik kanan pada kotak Heading 1 lalu pilih Modify...
    2. 
                
  2. Atur font menjadi Bookman Old Style atau Arial, ukuran 14 pt Bold, warna Automatic/Hitam.
    3. 
                
  3. Klik tombol Format di kiri bawah > pilih Paragraph...
    4. 
                
  4. Atur Spacing Before: 12 pt, After: 6 pt, dan centang kotak Keep with next (pada tab Line and Page Breaks) agar judul bab tidak pernah terputus sendirian di dasar halaman!
    5. 
                
  5. Klik OK dua kali untuk menyimpan perubahan. Seluruh judul Heading 1 di seluruh dokumen akan terbarui seketika.
    6. 
              


              
            


            
            

              
C

              

                Pemeriksaan Navigasi & Reorganisasi via Navigation Pane
                Ctrl + F / View > Navigation Pane
              

              

                Tekan Ctrl + F pada keyboard atau buka tab View lalu centang kotak Navigation Pane. Pilih tab Headings di panel sisi kiri.
              

              

                
✨

                

                  
Fitur Canggih Drag-and-Drop Navigation Pane:

                  

                    Di Microsoft Word, Anda dapat memindahkan satu bab atau subbab beserta seluruh paragraf dan tabel di bawahnya hanya dengan menyeret (drag-and-drop) judul tersebut di Navigation Pane! Anda tidak perlu lagi melakukan cut-and-paste manual yang rawan merusak format dokumen.
                  

                

              


              
            


            
            

              
D

              

                Penomoran Bertingkat Terikat Heading (Multilevel List)
                Home > Multilevel List
              

              

                Jangan mengetik penomoran naskah dinas (seperti A., 1., a., 1)) secara manual karena saat bab dipindahkan nomornya akan kacau. Tautkan penomoran bertingkat ke Styles:
              

              
    
                
  1. Pilih tab Home > klik ikon Multilevel List > pilih Define New Multilevel List...
    2. 
                
  2. Klik tombol More >> di pojok kiri bawah untuk membuka pengaturan lanjutan.
    3. 
                
  3. Pilih Level 1: Pada kotak Link level to style, pilih Heading 1.
    4. 
                
  4. Pilih Level 2: Pada kotak Link level to style, pilih Heading 2.
    5. 
                
  5. Pilih Level 3: Pada kotak Link level to style, pilih Heading 3.
    6. 
                
  6. Klik OK. Kini saat Anda menerapkan Heading 1 atau 2, nomor bab dan subbab akan bertambah otomatis!
    7. 
              


              
            


            
            

              
E

              

                Penyisipan Daftar Isi Otomatis (Table of Contents)
                References > Table of Contents
              

              

                Setelah seluruh judul menggunakan heading yang benar, buat Daftar Isi otomatis:
              

              
    
                
  1. Letakkan kursor pada halaman yang diperuntukkan bagi DAFTAR ISI.
    2. 
                
  2. Buka tab References > klik menu Table of Contents.
    3. 
                
  3. Pilih Custom Table of Contents...
    4. 
                
  4. Pastikan kotak Show page numbers dan Right align page numbers tercentang.
    5. 
                
  5. Pilih Tab leader dengan titik-titik (..........).
    6. 
                
  6. Pastikan Show levels: 3 (mencakup Heading 1, Heading 2, dan Heading 3).
    7. 
                
  7. Klik OK. Daftar Isi akan terbentuk secara instan dan presisi.
    8. 
              


              
            


            
            

              
F

              

                Pengujian & Pembaruan Daftar Isi (Update Field)
                Klik Kanan TOC > Update Field / F9
              

              

                Lakukan pengujian dinamis untuk membuktikan otomatisasi TOC berfungsi:
              

              
    
                
  1. Tambahkan satu judul subbagian baru pada Bab II, misalnya B.5 Standar Audit Dokumen dengan format Heading 2.
    2. 
                
  2. Kembali ke halaman Daftar Isi. Klik kanan di area Daftar Isi > pilih Update Field (atau tekan F9).
    3. 
                
  3. Pilih opsi Update entire table (Perbarui seluruh tabel) lalu klik OK.
    4. 
                
  4. Pastikan subbagian baru tersebut langsung muncul lengkap dengan nomor halamannya yang akurat!
    5.

    2. 
                
  2. Buka tab References > klik Insert Caption.
    3. 
                
  3. Pilih Label Tabel atau Gambar (buat label baru jika belum ada), ketik judulnya, lalu klik OK.
    4. 
                
  4. Pada kalimat isi paragraf, rujuk nomor tersebut via References > Cross-reference > pilih Reference type: Tabel/Gambar > Insert reference to: Only label and number.
    5. 
                
  5. Saat posisi gambar/tabel berpindah, tekan Ctrl + A lalu F9 untuk memperbarui seluruh nomor rujukan secara otomatis!

Bab III: Tata Letak & Template Dokumen

                
Rekayasa dokumen multi-section, decoupling Link to Previous, nomor Romawi vs Arab, tata letak Landscape, template .dotx, dan Content Controls.

              

            

            

              8 Langkah Praktik
              ▼
            

          


          

            
            

              
A

              

                Konsep & Implementasi Section Break vs Page Break
                Layout > Breaks
              

              

                Buka salinan berkas 02_Dokumen_Panjang_Section.docx. Pahami perbedaan fundamental antara Page Break dan Section Break:
              

              

                

                  
                    

                      Jenis Pemisah
                      Perilaku Format
                      Penggunaan Standar ASN
                    

                  
                  
                    

                      Page Break (Ctrl+Enter)
                      Memulai halaman baru tetapi tetap dalam pengaturan section yang sama.
                      Pindah halaman antar paragraf biasa dalam satu bab.
                    

                    

                      Section Break: Next Page
                      Membuat batas section baru yang independen pada halaman berikutnya.
                      Pemisah antara Sampul, Kata Pengantar, Bab Isi, dan Lampiran Landscape.
                    

                    

                      Section Break: Continuous
                      Membuat section baru pada halaman yang sama tanpa jeda halaman.
                      Mengubah teks 1 kolom menjadi 2 kolom di tengah halaman.
                    

                  
                

              

              

                Aktifkan tombol Show/Hide (¶) pada tab Home untuk melihat penanda :::: Section Break (Next Page) :::: agar tidak terhapus tanpa sengaja.
              


              
            


            
            

              
B

              

                Pemutusan Hubungan Header & Footer (Link to Previous)
                Kunci Sukses Nomor Berbeda!
              

              

                Secara default, saat Anda membuat Section 2, Microsoft Word akan tetap mengaitkan header dan footernya ke Section 1 (terlihat tulisan Same as Previous di pojok kanan). Anda WAJIB memutuskan tautan ini:
              

              
    
                
  1. Klik ganda (double-click) area Header pada halaman BAB I (Section 3).
    2. 
                
  2. Perhatikan tab ribbon Header & Footer yang muncul di bagian atas.
    3. 
                
  3. Klik tombol Link to Previous untuk MENONAKTIFKANNYA (sorotan tombol menjadi mati).
    4. 
                
  4. Gulir ke bawah dan klik di area Footer Section 3, lalu klik lagi tombol Link to Previous hingga mati!
    5. 
                
  5. Catatan: Header dan Footer memiliki tombol Link to Previous masing-masing yang berdiri sendiri!
    6. 
              


              
            


            
            

              
C

              

                Penomoran Halaman Campuran (Romawi Kecil vs Angka Arab Mulai dari 1)
                Insert > Page Number > Format Page Numbers
              

              

                Terapkan standar penomoran dokumen resmi ASN:
              

              

                
1. Halaman Sampul (Cover): Tidak boleh memiliki nomor halaman (pilih Different First Page atau hapus footer di Section 1).

                
2. Bagian Awal (Kata Pengantar, Daftar Isi): Nomor Romawi kecil di tengah bawah: i, ii, iii.

                
3. Bagian Isi (BAB I dst): Nomor Arab: 1, 2, 3 di kanan bawah / tengah bawah, dan WAJIB dimulai dari nomor 1.

              


              

              
            


            
            

              
D

              

                Tata Letak Campuran (Halaman Landscape Khusus Tabel Lebar)
                Layout > Orientation > Landscape
              

              

                Dokumen kedinasan sering kali memiliki tabel rekapitulasi data yang sangat lebar sehingga teks terpotong jika dipaksakan dalam orientasi Portrait:
              

              
    
                
  1. Letakkan kursor tepat sebelum judul tabel data lebar > sisipkan Layout > Breaks > Section Break (Next Page).
    2. 
                
  2. Letakkan kursor tepat sesudah akhir tabel > sisipkan lagi Section Break (Next Page).
    3. 
                
  3. Klik di halaman tabel > pilih Layout > Orientation > Landscape.
    4. 
                
  4. Periksa dokumen: Halaman tabel kini menjadi Landscape mendatar yang leluasa, sementara halaman sebelum dan sesudahnya tetap Portrait berdiri sempurna!
    5. 
              


              
            


            
            

              
E

              

                Pembuatan & Penggunaan Template Word Standar (.dotx)
                File > Save As > Word Template (*.dotx)
              

              

                Jangan pernah membagikan draft kedinasan dengan menyalin-tempel (copy-paste) dokumen lama yang berisiko menyisakan data kasus orang lain. Buat Template resmi:
              

              
    
                
  1. Hapus seluruh isi paragraf spesifik kasus, tetapi pertahankan struktur judul, style, section break, margin, dan header/footer.
    2. 
                
  2. Ganti teks spesifik dengan instruksi pengisian umum dalam tanda kurung siku, misalnya: [Tuliskan Latar Belakang Kegiatan di Sini].
    3. 
                
  3. Pilih File > Save As > ubah tipe berkas Save as type menjadi Word Template (*.dotx).
    4. 
                
  4. Uji coba template: Klik ganda berkas .dotx tersebut. Word akan otomatis membuka dokumen baru (Document1) berbasis template tanpa pernah menimpa berkas master aslinya!
    5. 
              


              
            


            
            

              
F

              

                Pemasangan Form Isian Content Controls (Tab Developer)
                Developer > Controls
              

              

                Untuk template formulir resmi (seperti Nota Dinas atau SPT), cegah pengguna merusak format tata letak dengan Content Controls:
              

              
    
                
  1. Jika tab Developer belum muncul: Klik kanan ribbon > Customize the Ribbon > centang kotak Developer.
    2. 
                
  2. Sisipkan Plain Text Content Control pada bagian Nama Pejabat dan NIP.
    3. 
                
  3. Sisipkan Date Picker Content Control pada baris tanggal surat naskah dinas.
    4. 
                
  4. Sisipkan Drop-Down List Content Control untuk pilihan Unit Kerja / SKPD Pemprov DKI.
    5. 
              


              
            


            
            

              
G

Komentar (Modern Comments) dirancang untuk memberikan umpan balik kontekstual, pertanyaan telaah, diskusi thread, dan catatan telaah naskah dinas tanpa mengubah isi teks dokumen secara langsung.

              

            

          


          
          

            

              Soal #11
              
Izin paling tepat untuk pihak yang hanya memberi saran adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Memberikan izin Reviewing (Can Review) memastikan penelaah hanya dapat memberi komentar dan menyarankan perubahan (secara otomatis terlacak lewat Track Changes) tanpa kewenangan mengubah naskah master secara permanen.

              

            

          


          
          

            

              Soal #12
              
Cara terbaik menghindari konflik versi adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Menerapkan single source of truth dengan mengedit dokumen bersama (co-authoring) di cloud resmi (OneDrive/SharePoint/Server Dinas) mencegah kekacauan akibat peredaran belasan file lokal yang saling bertolak belakang.

              

            

          


          
          

            

              Soal #13
              
Fungsi Navigation Pane adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Navigation Pane (Ctrl+F atau View > Navigation Pane) menampilkan outline hierarki dokumen secara interaktif, memungkinkan penataan ulang bab dengan drag-and-drop, dan lompat ke bagian naskah secara instan.

              

            

          


          
          

            

              Soal #14
              
Jika nomor halaman isi harus dimulai dari 1, pilih ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Pada kotak dialog Page Number Format, memilih opsi Start at: 1 mereset penomoran halaman pada section tersebut ke angka 1 (misalnya saat beralih dari bagian pengantar bernomor Romawi ke Bab I naskah utama).

              

            

          


          
          

            

              Soal #15
              
Langkah akhir sebelum dokumen review dinyatakan bersih adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Memeriksa Reviewing Pane memastikan semua revisi telah diputuskan (Accept/Reject) dan semua komentar telah ditandai Resolve atau dihapus, lalu dilanjutkan pembersihan jejak reviewer melalui Document Inspector. Memilih No Markup saja tidak menghapus revisi yang tertinggal.

              

            

          


          
          

            

              Soal #16
              
Nomor bab tidak konsisten setelah bagian dipindahkan. Perbaikan paling tepat adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Menautkan Multilevel List ke Style Heading (Define New Multilevel List > Link level to style: Heading 1, 2) membuat penomoran bab dan subbab memperbarui dirinya sendiri secara otomatis saat paragraf dipindahkan atau disisipkan.

              

            

          


          
          

            

              Soal #17
              
Semua label menampilkan penerima yang sama. Penyebab paling mungkin adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Jika aturan <> tidak disisipkan sebelum field pertama pada kotak label ke-2 dan seterusnya, Word akan terus mengulang data penerima pertama di seluruh stiker label dalam satu halaman kertas.

              

            

          


          
          

            

              Soal #18
              
Header section sebelumnya ikut berubah ketika header baru diedit. Tindakan korektif adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Gejala ini terjadi karena hubungan antar-section masih aktif. Solusinya adalah masuk ke header section yang baru lalu klik Link to Previous pada tab Header & Footer untuk mematikan keterhubungan tersebut (unlink).

              

            

          


          
          

            

              Soal #19
              
Risiko utama tautan publik edit untuk dokumen kedinasan adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Membagikan link edit tanpa proteksi akun/autentikasi memungkinkan pihak mana pun di luar instansi mengubah isi naskah dinas, membocorkan data pribadi (melanggar Pergub DKI No. 14/2020), dan merusak integritas hukum dokumen.

              

            

          


          
          

            

              Soal #20
              
Dua reviewer mengirim salinan revisi tanpa Track Changes. Fitur paling sesuai untuk merekonsiliasi perubahan adalah ...

            

            

              

                
                
                
                
              

              

                💡 Pembahasan Resmi (Lampiran 1 BPSDM):
                
Fitur Compare atau Combine Documents (Review > Compare) secara cerdas membandingkan dua versi dokumen Word terpisah dan menyatukan seluruh perbedaan kata, kalimat, maupun format ke dalam satu naskah baru yang dilengkapi tanda revisi Track Changes.
